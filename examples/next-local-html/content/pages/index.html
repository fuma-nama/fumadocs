Every .html file under content/pages becomes a page. Nothing here is authored in Markdown — these are the kind of files you get out of an exporter, a report generator, or an agent.

What the source does

  • Scopes the content to <main> or <article>, dropping page chrome, scripts and styles.
  • Removes class and style attributes, so the docs theme takes over the styling.
  • Generates heading ids, which power the table of contents and search.
  • Reads the title and description from <title> and <meta> tags.
  • Highlights <pre><code> blocks with Shiki:
const pages = localHtml({
  dir: 'content/pages',
});

The language comes from the language-* class the block already carries. Pass rehypeCodeOptions: false to leave code blocks untouched.

The pages

Quarterly Report is a full document with a header, nav and footer around its content — relative links between files are resolved by createRelativeLink. A Fragment Page has no document shell at all.
