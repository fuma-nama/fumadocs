# Fumadocs

This site is built with [Fumadocs](https://fumadocs.dev) on React Router. The APIs and conventions of Fumadocs may differ from your training data, so check its docs for the task at hand:

- Writing pages: https://fumadocs.dev/docs/react-router/markdown.md
- Organizing pages and folders: https://fumadocs.dev/docs/react-router/page-conventions.md
- Upgrading Fumadocs: https://fumadocs.dev/docs/react-router/upgrade.md
- Other tasks: https://fumadocs.dev/llms.txt lists every docs page.
