This example documents a GraphQL schema with Fumadocs GraphQL, generated from a single SDL file (`schema.graphql`) and example operations (`examples/store.graphql`).

## API Reference

Browse the generated reference pages under **API Reference**:

- **Queries, Mutations, Subscriptions**: a page per operation with its arguments, return type, code samples and examples.
- **Objects, Interfaces, Unions, Enums, Input Objects, Scalars**: a page per named type, enabled with `includeTypes: true` in `lib/source.ts`.

## Playground

Open **Try in Playground** on an operation page, then press **Send** to send the operation to the endpoint.

This example ships a mock endpoint at `/api/graphql` that responds with sample values, replace it with your own GraphQL server.
