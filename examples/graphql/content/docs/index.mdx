This example documents a GraphQL schema with Fumadocs GraphQL, generated from a single SDL file (`schema.graphql`).

## API Reference

Browse the generated reference pages under **API Reference**:

- **Queries, Mutations, Subscriptions**: a page per operation with arguments, return type, and generated example queries/responses.
- **Objects, Interfaces, Unions, Enums, Input Objects, Scalars**: a page per named type, with cross-linked type references.

## Playground

Each operation page includes an interactive playground — press **Run** to send the operation to the endpoint.

This example ships a mock endpoint at `/api/graphql` that responds with sample values, replace it with your own GraphQL server.
