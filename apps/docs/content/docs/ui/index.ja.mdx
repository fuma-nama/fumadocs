**Fumadocs UI** は、ドキュメントサイト向けに美しくデザインされたテーマを提供します。

ドキュメントサイト向けのインタラクティブなコンポーネントやレイアウトが多数同梱されているため、コードの保守コストを抑えつつ、定期的な UI の改善を取り込むことができます。

[Fumadocs CLI](/docs/cli) を使ってコンポーネントをローカルにインストールすれば、すべてを自由にカスタマイズすることもできます。
