**Fumadocs UI** は、ドキュメントサイト向けに美しくデザインされたテーマを提供します。

ドキュメントサイト向けのインタラクティブなコンポーネントやレイアウトが多数同梱されているため、コードの保守コストを低く抑えつつ、UI の改善を継続的に取り込むことができます。

また、[Fumadocs CLI](/docs/cli) を使ってコンポーネントをローカルにインストールすれば、すべてを自由に制御できます。
