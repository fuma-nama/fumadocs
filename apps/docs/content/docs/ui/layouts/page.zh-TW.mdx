Page 是文件頁面的基本元素，包含目錄、
頁尾與 Breadcrumb。

<Customization />

## 使用方式 [#usage]

請依照您使用的版面配置匯入。

```tsx title="page.tsx" tab="Docs Layout"
import { DocsPage, DocsDescription, DocsTitle, DocsBody } from 'fumadocs-ui/layouts/docs/page';

<DocsPage>
  <DocsTitle>title</DocsTitle>
  <DocsDescription>description</DocsDescription>
  <DocsBody>
    <h2>This heading looks good!</h2>
    It applies the Typography styles, wrap your content here.
  </DocsBody>
</DocsPage>;
```

```tsx title="page.tsx" tab="Notebook Layout"
import { DocsPage, DocsDescription, DocsTitle, DocsBody } from 'fumadocs-ui/layouts/notebook/page';

<DocsPage>
  <DocsTitle>title</DocsTitle>
  <DocsDescription>description</DocsDescription>
  <DocsBody>
    <h2>This heading looks good!</h2>
    It applies the Typography styles, wrap your content here.
  </DocsBody>
</DocsPage>;
```

<Callout type="info" title="小提示">
  除了在 `page.tsx` 中以 `DocsTitle` 算繪標題，您也可以將標題直接寫在 MDX 檔案中，
  標題便會在 MDX 內文中算繪。
</Callout>

### 頁面操作 [#page-actions]

顯示 GitHub 連結，以及開啟各 AI 工具的快捷連結。

```tsx
import { DocsPage, ViewOptionsPopover } from 'fumadocs-ui/layouts/<layout>/page';

const githubUrl = `https://github.com/fuma-nama/fumadocs/blob/main/content/docs/${encodeURI(page.path)}`

<DocsPage>
  <ViewOptionsPopover githubUrl={githubUrl} />
</DocsPage>;
```

### 最後更新時間 [#last-updated-time]

顯示頁面的最後更新時間。

```tsx
import { DocsPage, PageLastUpdate } from 'fumadocs-ui/layouts/<layout>/page';

const lastModifiedTime: Date | undefined;

<DocsPage>
  {/* 其他內容 */}
  {lastModifiedTime && <PageLastUpdate date={lastModifiedTime} />}
</DocsPage>;
```

至於 `lastModifiedTime`，您可以視需求使用不同的版本控制來源，例如 Github 或 CMS。

<Tabs items={['Fumadocs MDX', 'GitHub API']}>
  <Tab>
    您可以啟用 [`lastModified`](/docs/mdx/last-modified)。

    ```tsx
    import { source } from '@/lib/source';
    const page = source.getPage(['...']);

    const lastModifiedTime = page.data.lastModified;
    ```
  </Tab>

  <Tab>
    若文件託管在 Github 上，您可以使用
    [`getGithubLastEdit`](/docs/headless/utils/git-last-edit) 工具函式。

    ```tsx
    import { getGithubLastEdit } from 'fumadocs-core/content/github';

    const lastModifiedTime = await getGithubLastEdit({
      owner: 'fuma-nama',
      repo: 'fumadocs',
      // Git 中的檔案路徑
      path: `content/docs/${page.path}`,
    });
    ```
  </Tab>
</Tabs>

## 設定 [#configurations]

### 完整模式 [#full-mode]

若要讓頁面延展並填滿所有可用空間，請將 `full` 傳入頁面元件。
這會強制以彈出框 (popover) 的形式顯示目錄。

```tsx
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

<DocsPage full>...</DocsPage>;
```

### 目錄 [#table-of-contents]

文章中所有標題的概覽，需傳入一個標題陣列。

若是 Markdown 和 MDX 文件，您可以使用
[目錄工具](/docs/headless/utils/get-toc)取得。像 Fumadocs MDX 這類內容來源已內建此功能，開箱即用。

```tsx
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

<DocsPage toc={headings}>...</DocsPage>;
```

您可以透過 `tableOfContent` 自訂目錄，在較小的裝置上則使用 `tableOfContentPopover`。

```tsx title="page.tsx"
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

return (
  <DocsPage tableOfContent={options} tableOfContentPopover={options}>
    ...
  </DocsPage>
);
```

#### 樣式 [#style]

為目錄選擇其他樣式：

<Wrapper>
  <TOCStylePreview>
    <TOCStyle value="normal">一條軌道線，並在作用中的標題上顯示滑塊 (預設) 。</TOCStyle>

    <TOCStyle value="clerk">
      一條隨標題層級變化的軌道線，靈感來自 [Clerk](https://clerk.com)。
    </TOCStyle>

    <TOCStyle value="block">不顯示軌道線，改由一個區塊在作用中的標題後方滑動。</TOCStyle>
  </TOCStylePreview>
</Wrapper>

```tsx
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

<DocsPage
  tableOfContent={{
    style: 'clerk',
  }}
>
  ...
</DocsPage>;
```

#### 替換目錄 [#replace-toc]

若要替換此元件：

```tsx tab="page.tsx"
import { TOCProvider, TOC, TOCPopover } from './my-toc';

return (
  <DocsPage
    slots={{
      toc: {
        provider: TOCProvider,
        main: TOC,
        popover: TOCPopover,
      },
    }}
  >
    ...
  </DocsPage>
);
```

```tsx tab="my-toc.tsx"
'use client';
import type {
  TOCProps,
  TOCPopoverProps,
  TOCProviderProps,
} from 'fumadocs-ui/layouts/<layout>/page/slots/toc';

export function TOCProvider({ toc, children }: TOCProviderProps) {
  // 接收目錄項目，可透過 React context 向下傳遞
  console.log(toc);
  return children;
}

export function TOC(props: TOCProps) {
  return <div>Hello World</div>;
}

export function TOCPopover(props: TOCPopoverProps) {
  return <div>Popover</div>;
}
```

您可以使用 Fumadocs CLI，以預設實作為基礎開始修改：

```bash tab="Docs Layout"
npx @fumadocs/cli add slots/docs/page/toc
```

```bash tab="Notebook Layout"
npx @fumadocs/cli add slots/notebook/page/toc
```

```bash tab="Flux Layout"
npx @fumadocs/cli add slots/flux/page/toc
```

### 頁尾 [#footer]

頁尾是一種導覽元素，提供兩個按鈕，可跳至上一頁與下一頁。若未指定，則會顯示從頁面樹找到的相鄰頁面。

您可以透過 `footer` prop 自訂頁尾：

```tsx
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

<DocsPage footer={options}>...</DocsPage>;
```

### Breadcrumb [#breadcrumb]

導覽元素，僅在使用者瀏覽資料夾內的頁面時顯示。

您可以透過 `breadcrumb` 選項自訂 Breadcrumb：

```tsx
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';

<DocsPage breadcrumb={options}>...</DocsPage>;
```

### 容器 [#container]

Container 控制文章的外層容器，其中包覆 Breadcrumb、內文與頁尾。

若要替換頁面容器：

```tsx tab="page.tsx"
import { DocsPage } from 'fumadocs-ui/layouts/<layout>/page';
import { Container } from './my-container';

<DocsPage
  slots={{
    container: Container,
  }}
/>;
```

```tsx tab="my-container.tsx"
'use client';

export function Container(props: React.ComponentProps<'article'>) {
  return <div />;
}
```

您可以使用 Fumadocs CLI，以預設實作為基礎開始修改：

```bash tab="Docs Layout"
npx @fumadocs/cli add slots/docs/page/container
```

```bash tab="Notebook Layout"
npx @fumadocs/cli add slots/notebook/page/container
```

```bash tab="Flux Layout"
npx @fumadocs/cli add slots/flux/page/container
```
