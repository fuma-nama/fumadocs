## 使用方式 [#usage]

將您的頁面樹傳給元件。

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import { baseOptions } from '@/lib/layout.shared';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout {...baseOptions()} tree={tree}>
      {children}
    </DocsLayout>
  );
}
```

關於 [`links`](/docs/ui/layouts/links) 與 [`nav`](/docs/ui/layouts/nav) 選項的詳細說明，請參閱相關文件。

### 側邊欄項目 [#sidebar-items]

自訂側邊欄的導覽連結。

<div className="flex justify-center items-center *:max-w-[200px] bg-linear-to-br from-fd-primary/10 rounded-xl border">
  ![側邊欄](/docs/sidebar.png)
</div>

側邊欄項目是根據您傳給 `<DocsLayout />` 的頁面樹算繪而成。

若頁面樹來自 [`loader()`](/docs/headless/source-api)，則會依據您的檔案結構產生，詳情請參閱[可用的模式](/docs/page-conventions)。

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import { source } from '@/lib/source';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout
      tree={source.getPageTree()}
      // 其他 props
    >
      {children}
    </DocsLayout>
  );
}
```

您也可以直接寫死在程式碼中：

```tsx title="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import type { ReactNode } from 'react';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <DocsLayout
      tree={{
        name: 'docs',
        children: [],
      }}
      // 其他 props
    >
      {children}
    </DocsLayout>
  );
}
```

### 版面配置頁籤 (下拉選單)  [#layout-tabs]

版面配置頁籤是具有頁籤行為的資料夾，只會顯示目前開啟頁籤的內容。

<div className="flex justify-center items-center *:max-w-[360px] bg-linear-to-br from-fd-primary/10 rounded-xl border">
  ![版面配置頁籤](/docs/sidebar-tabs.png)
</div>

預設情況下，頁籤觸發器會以**下拉選單**元件呈現 (除非其中有項目處於啟用狀態，否則會隱藏) 。

頁籤是根據頁面樹產生的，您可以在資料夾中建立 `meta.json` 檔案，將資料夾標記為[根資料夾](/docs/page-conventions#root-folder)：

```json title="content/docs/my-folder/meta.json"
{
  "title": "Name of Folder",
  "description": "The description of root folder (optional)",
  "root": true
}
```

或者明確指定：

```tsx title="/app/docs/layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';

<DocsLayout
  tabs={[
    {
      title: 'Components',
      description: 'Hello World!',
      // 位於 `/docs/components` 及其子路由（例如 `/docs/components/button`）時會啟用
      url: '/docs/components',

      // 您也可以另外指定一組 URL，符合時即會啟用此項目
      // urls: new Set(['/docs/test', '/docs/components']),
    },
  ]}
/>;
```

若要停用，請將其設為 `false`：

```tsx
import { DocsLayout } from 'fumadocs-ui/layouts/docs';

<DocsLayout tabs={false} />;
```

<Callout title="需要進一步自訂？">
  您可以為 [文件版面配置](/docs/ui/layouts/docs) 元件指定 `banner`。

  ```tsx
  import { DocsLayout, type DocsLayoutProps } from 'fumadocs-ui/layouts/docs';
  import type { ReactNode } from 'react';
  import { baseOptions } from '@/lib/layout.shared';
  import { source } from '@/lib/source';

  export default function Layout({ children }: { children: ReactNode }) {
    return (
      <DocsLayout
        {...baseOptions()}
        tree={source.getPageTree()}
        sidebar={{
          // [!code ++]
          banner: <div>Hello World</div>,
        }}
      >
        {children}
      </DocsLayout>
    );
  }
  ```
</Callout>

### 頁籤群組 [#tabs-groups]

頁籤會依照[根類型](/docs/page-conventions#root-type)分組，目前頁面路徑上的每個根資料夾都會有各自的下拉選單。

<Files>
  <Folder name="v2 (root: version)" defaultOpen>
    <Folder name="framework (root: true)" defaultOpen>
      <File name="quickstart.mdx" className="text-fd-primary! bg-fd-primary/10!" />
    </Folder>

    <Folder name="headless (root: true)">
      <File name="quickstart.mdx" />
    </Folder>
  </Folder>

  <Folder name="v1 (root: version)">
    <Folder name="framework (root: true)">
      <File name="quickstart.mdx" />
    </Folder>
  </Folder>
</Files>

在 `v2/framework/quickstart.mdx` 頁面中，側邊欄會顯示兩個下拉選單，分別用來切換版本與章節：

<div className="flex justify-center items-center *:max-w-[360px] bg-linear-to-br from-fd-primary/10 rounded-xl border">
  ![頁籤群組](/docs/sidebar-tabs-groups.png)
</div>

選取選項後，會前往該根資料夾中的同一頁面；若該頁面不存在，則會改為前往其索引頁面。完整範例請參閱[版本控制](/docs/navigation#versioning)。

### 側邊欄元件 [#sidebar-components]

您可以替換部分用來算繪頁面樹的元件。

```tsx tab="layout.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import { SidebarSeparator } from './layout.client';

<DocsLayout
  sidebar={{
    enabled: true,
    components: {
      Separator: SidebarSeparator,
    },
  }}
/>;
```

```tsx tab="layout.client.tsx"
'use client';
import * as Base from 'fumadocs-ui/components/sidebar/base';

export function SidebarSeparator({ className, style, children, ...props }: ComponentProps<'p'>) {
  const depth = Base.useFolderDepth();

  return (
    <Base.SidebarSeparator
      className={cn('[&_svg]:size-4 [&_svg]:shrink-0', className)}
      style={{
        paddingInlineStart: `calc(${2 + 3 * depth} * var(--spacing))`,
        ...style,
      }}
      {...props}
    >
      {children}
    </Base.SidebarSeparator>
  );
}
```

## AI 聊天 [#ai-chat]

將您的聊天面板連同其開啟狀態傳入 `aiChat`，版面配置會在寬螢幕上將它顯示於頁面旁，在較小的螢幕上則讓它浮動於頁面上方。

```tsx
<DocsLayout aiChat={{ open, onOpenChange: setOpen, panel: <MyChat />, trigger: true }} />
```

此版面配置本身不含「詢問 AI」按鈕，`trigger` 會加入一個浮動按鈕。

如需現成的聊天介面，請參閱[詢問 AI](/docs/integrations/llms#ask-ai)。

## 進階 [#advanced]

### 預先載入 [#prefetching]

Fumadocs 使用您的 React 框架所提供的 `<Link />` 元件，並沿用其預設的預先載入行為。

在 Vercel 上，預先載入請求可能會增加 Serverless Functions 與 Data Cache 的用量。
在其他部分託管平台上，也可能因此觸及用量限制。

您可以停用預先載入以減少預先載入請求的數量，或明確啟用：

```tsx
import { DocsLayout } from 'fumadocs-ui/layouts/docs';

<DocsLayout sidebar={{ prefetch: false }} />;
```

### 版面配置系統 [#the-layout-system]

處理版面配置並不容易，Fumadocs UI 需要一套具備以下特性的做法：

* **可組合：** 版面配置元件應能輕鬆管理自身的位置與尺寸，最好能直接在原處完成。
* **彈性：** 系統應避免依賴固定數值或高度，讓外部元件 (例如 AI 聊天介面) 能無縫整合。
* **連貫：** 元件應能回應其他元件的變化，例如以動畫呈現側邊欄的收合。
* **可預測：** 版面配置屬性應集中管理，讓您能從原始碼輕易預見最終結果。
* **相容：** 解決方案應只使用 Baseline Widely Available 的 CSS 功能，以支援舊版瀏覽器。

Fumadocs UI 透過網格系統來達成這些目標：

```css
#nd-docs-layout {
  grid-template:
    'sidebar header toc'
    'sidebar toc-popover toc'
    'sidebar main toc' 1fr / minmax(var(--fd-sidebar-col), 1fr) minmax(0, var(--fd-page-col))
    minmax(min-content, 1fr);

  --fd-docs-row-1: var(--fd-banner-height, 0px);
  --fd-docs-row-2: calc(var(--fd-docs-row-1) + var(--fd-header-height));
  --fd-docs-row-3: calc(var(--fd-docs-row-2) + var(--fd-toc-popover-height));
  --fd-sidebar-col: var(--fd-sidebar-width);
  --fd-page-col: calc(
    var(--fd-layout-width, 97rem) - var(--fd-sidebar-width) - var(--fd-toc-width)
  );
  --fd-sidebar-width: 0px;
  --fd-toc-width: 0px;

  --fd-header-height: 0px;
  --fd-toc-popover-height: 0px;
}
```

* 版面配置容器採用 grid 版面，並設定了 `grid-template` 以確保結果可預期。
* `--fd-docs-row-*` 定義每一列的頂部偏移量，讓帶有 `position: sticky` 的元素能套用正確的頂部偏移量。
* `--fd-*-width` 與 `--fd-*-height` 由版面配置元件透過 CSS 設定，是維持 grid 結構及計算 `--fd-docs-row-*` 不可或缺的值。
* `--fd-*-col` 是動態值，會隨狀態變化而更新 (例如側邊欄收合時，`--fd-sidebar-col` 會變為 `0px`) 。

預設版面配置與 Notebook 版面配置都採用這套系統。
