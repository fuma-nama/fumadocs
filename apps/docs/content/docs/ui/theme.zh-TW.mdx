## 概覽 [#overview]

Fumadocs UI 透過 Tailwind CSS 預設集加入專屬的色彩、動畫與工具類別。

### 設定 [#setup]

僅支援 Tailwind CSS v4，此預設組合也會將 Fumadocs UI 本身加入來源：

```css title="Tailwind CSS"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
```

若您使用 **Shadcn UI**，可以改用 `shadcn` 預設樣式。Fumadocs UI 會沿用您 Shadcn UI 主題中的色彩。

```css
@import 'tailwindcss';
@import 'fumadocs-ui/css/shadcn.css';
@import 'fumadocs-ui/css/preset.css';
```

詳情請參閱[色彩](#colors)。

### Preflight 變更 [#preflight-changes]

使用 Tailwind CSS 外掛或預先建置的樣式表時，預設的邊框、文字與背景
顏色都會隨之改變。

### 淺色／深色模式 [#lightdark-modes]

Fumadocs 透過 [`next-themes`](https://github.com/pacocoursey/next-themes) 支援淺色／深色模式，此功能已內建於 Root Provider 中。

詳情請參閱 [Root Provider](/docs/ui/layouts/root-provider#theme-provider)。

### RTL 版面配置 [#rtl-layout]

支援 RTL (由右至左) 版面配置。

若要啟用 RTL，請在 body 與 root provider 上將 `dir` prop 設為 `rtl`。

```tsx
import { RootProvider } from 'fumadocs-ui/provider/<framework>';
import type { ReactNode } from 'react';

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body dir="rtl">
        <RootProvider dir="rtl">{children}</RootProvider>
      </body>
    </html>
  );
}
```

### 版面配置寬度 [#layout-width]

您可以使用 CSS 變數自訂文件版面配置的最大寬度。

```css
:root {
  --fd-layout-width: 1400px;
}
```

### 排版 [#typography]

我們內建了一個外掛，從 [Tailwind CSS Typography](https://tailwindcss.com/docs/typography-plugin) fork 而來。

此外掛提供 `prose` class，以及可用來自訂樣式的變體。

```tsx
<div className="prose">
  <h1>Good Heading</h1>
</div>
```

將 `prose-sm` 或 `prose-xs` 與 `prose` 搭配使用，即可套用 `text-sm` 或 `text-xs` 的字級與行高，字重也會經過視覺校正：

```tsx
<div className="prose prose-sm">...</div>
```

> 此外掛專為搭配 Fumadocs UI 的 MDX 元件而設計，可能會與 `@tailwindcss/typography` 產生衝突。
>
> 若您需要改用 `@tailwindcss/typography` 而非預設外掛，請[設定 `className` 選項](https://github.com/tailwindlabs/tailwindcss-typography/blob/main/README.md#changing-the-default-class-name)以避免衝突。
>
> ```sass
> @import 'tailwindcss';
> @plugin "@tailwindcss/typography" {
>   className: wysiwyg;
> }
> ```
