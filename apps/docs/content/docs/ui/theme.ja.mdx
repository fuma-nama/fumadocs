## 概要 [#overview]

Fumadocs UI は、Tailwind CSS のプリセットによって独自のカラー、アニメーション、ユーティリティを追加します。

### セットアップ [#setup]

サポートされているのは Tailwind CSS v4 のみです。プリセットには Fumadocs UI 自体のソースも含まれます:

```css title="Tailwind CSS"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
```

**Shadcn UI** を使用している場合は、代わりに `shadcn` プリセットを使用できます。Fumadocs UI は Shadcn UI のテーマの色をそのまま使用します。

```css
@import 'tailwindcss';
@import 'fumadocs-ui/css/shadcn.css';
@import 'fumadocs-ui/css/preset.css';
```

詳しくは[カラー](#colors)を参照してください。

### Preflight の変更 [#preflight-changes]

Tailwind CSS プラグインまたはビルド済みのスタイルシートを使用すると、ボーダー、テキスト、背景のデフォルトの色が変更されます。

### ライト/ダークモード [#lightdark-modes]

Fumadocs は [`next-themes`](https://github.com/pacocoursey/next-themes) を使用してライト/ダークモードをサポートしています。`next-themes` は Root Provider に含まれています。

詳しくは [Root Provider](/docs/ui/layouts/root-provider#theme-provider) を参照してください。

### RTL レイアウト [#rtl-layout]

RTL (右から左) レイアウトに対応しています。

RTL を有効にするには、body 要素とルートプロバイダーの `dir` prop を `rtl` に設定してください。

```tsx
import { RootProvider } from 'fumadocs-ui/provider/<framework>';
import type { ReactNode } from 'react';

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body dir="rtl">
        <RootProvider dir="rtl">{children}</RootProvider>
      </body>
    </html>
  );
}
```

### レイアウトの幅 [#layout-width]

CSS 変数を使って、Docs レイアウトの最大幅をカスタマイズできます。

```css
:root {
  --fd-layout-width: 1400px;
}
```

### タイポグラフィ [#typography]

[Tailwind CSS Typography](https://tailwindcss.com/docs/typography-plugin) をフォークした組み込みプラグインを提供しています。

このプラグインは `prose` クラスと、それをカスタマイズするためのバリアントを追加します。

```tsx
<div className="prose">
  <h1>Good Heading</h1>
</div>
```

`prose` と併せて `prose-sm` または `prose-xs` を使用すると、`text-sm` または `text-xs` と同じフォントサイズと行の高さが適用され、フォントウェイトも見た目に合わせて調整されます：

```tsx
<div className="prose prose-sm">...</div>
```

> このプラグインは Fumadocs UI の MDX コンポーネントと組み合わせて使うことを前提としているため、`@tailwindcss/typography` と競合する場合があります。
>
> デフォルトのプラグインではなく `@tailwindcss/typography` を使う必要がある場合は、競合を避けるために [`className` オプションを設定](https://github.com/tailwindlabs/tailwindcss-typography/blob/main/README.md#changing-the-default-class-name)してください。
>
> ```sass
> @import 'tailwindcss';
> @plugin "@tailwindcss/typography" {
>   className: wysiwyg;
> }
> ```
