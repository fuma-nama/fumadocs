## 概要 [#overview]

検索 UI は [`<RootProvider />`](/docs/ui/layouts/root-provider) でカスタマイズできます。

```tsx title="app/layout.tsx"
import { RootProvider } from 'fumadocs-ui/provider/<framework>';
import type { ReactNode } from 'react';
import { SearchDialog } from '@/components/my-search-dialog';

export default function Layout({ children }: { children: ReactNode }) {
  return (
    <html>
      <body>
        <RootProvider
          // [!code highlight:4]
          search={{
            enabled: false, // 検索を完全に無効化
            SearchDialog, // 検索ダイアログを置き換え
          }}
        >
          {children}
        </RootProvider>
      </body>
    </html>
  );
}
```

### ホットキー [#hot-keys]

検索ダイアログを開くホットキーをカスタマイズできます。デフォルトは <kbd>⌘</kbd> <kbd>K</kbd> または <kbd>Ctrl</kbd> <kbd>K</kbd> です。

```tsx
import { RootProvider } from 'fumadocs-ui/provider/<framework>';

<RootProvider
  search={{
    hotKey: [
      {
        display: 'K',
        key: 'k', // キーコード、またはキーが押されたかどうかを判定する関数
      },
    ],
  }}
>
  {children}
</RootProvider>;
```

## カスタムUI [#custom-ui]

Fumadocs UI は、高度な用途向けに低レベルな `<SearchDialog />` コンポーネントも公開しています。これを使えば、独自の検索ダイアログを作成してデフォルトの検索ダイアログと置き換えられます。

```tsx twoslash
'use client';
import React from 'react';
import { useFetchSearch } from 'fumadocs-core/search/client';
import {
  SearchDialog,
  SearchDialogClose,
  SearchDialogContent,
  SearchDialogHeader,
  SearchDialogFooter,
  SearchDialogIcon,
  SearchDialogInput,
  SearchDialogList,
  SearchDialogOverlay,
  type SharedProps,
} from 'fumadocs-ui/components/dialog/search';
import { useI18n } from 'fumadocs-ui/contexts/i18n';

export default function DefaultSearchDialog(props: SharedProps) {
  const { locale } = useI18n(); // (任意)i18n 用
  const search = useFetchSearch({
    locale,
  });

  return (
    <SearchDialog {...search} {...props}>
      <SearchDialogOverlay />
      <SearchDialogContent>
        <SearchDialogHeader>
          <SearchDialogIcon />
          <SearchDialogInput />
          <SearchDialogClose />
        </SearchDialogHeader>
        <SearchDialogList />
        <SearchDialogFooter>{/* フッターの項目 */}</SearchDialogFooter>
      </SearchDialogContent>
    </SearchDialog>
  );
}
```

### コンテンツレンダラー [#content-renderer]

検索アイテムの Markdown コンテンツを独自にレンダリングしたい場合は、`renderMarkdown` を渡してください。

```tsx title="components/search.tsx"
<SearchDialogList
  // [!code highlight:8]
  Item={(props) => (
    <SearchDialogListItem
      {...props}
      renderMarkdown={(text) => {
        // ...
      }}
    />
  )}
/>
```

### テーブル [#tables]

結果に含まれるテーブルのレンダリング方法をカスタマイズできます。カスタムの `Table` を使うと、行のレンダリングを独自に行えます。

```tsx title="components/search.tsx"
<SearchDialogList
  // カードを使わずに行を表示する
  Table={({ table, Item, onSelect }) =>
    table.rows.map((row) => (
      <Fragment key={row.id}>{Item({ item: row, onClick: () => onSelect(row) })}</Fragment>
    ))
  }
/>
```

### ハイライト [#highlights]

検索クエリに一致した箇所は [CSS Custom Highlight API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Custom_Highlight_API) でハイライトされます。スタイルは `::highlight(fd-search)` で指定してください。

```css title="global.css"
::highlight(fd-search) {
  color: var(--color-fd-primary-foreground);
  background-color: var(--color-fd-primary);
}
```

`<SearchDialogList />` は、`<SearchDialog />` から渡された `data` のクエリをハイライトします。`data` がない場合は、検索入力の内容をハイライトします。

結果を独自にレンダリングする場合は、`useHighlightQuery()` を使ってハイライトしてください。

```tsx title="components/search-result.tsx"
'use client';
import { useHighlightQuery } from 'fumadocs-core/search/client';
import type { ReactNode } from 'react';

export function SearchResult({ query, children }: { query: string; children: ReactNode }) {
  const ref = useHighlightQuery(query);

  return <div ref={ref}>{children}</div>;
}
```

コンポーネントのバッジのように、`data-highlight-ignore` を持つ要素内のテキストはハイライトされません。
