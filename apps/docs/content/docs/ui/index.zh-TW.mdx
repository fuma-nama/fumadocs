**Fumadocs UI** 為文件網站提供設計精美的主題。

它內建許多專為文件網站打造的互動式元件與版面配置，讓您只需極低的程式碼維護成本，就能持續獲得 UI 的定期改進。

您也可以使用 [Fumadocs CLI](/docs/cli) 將元件安裝到本機，以取得完整的控制權。
