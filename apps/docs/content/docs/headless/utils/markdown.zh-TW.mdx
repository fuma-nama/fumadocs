## 概覽 [#overview]

`fumadocs-core/server` 會將 React 伺服器元件算繪成 Markdown 文件：

```tsx tab="Input"
import { renderToMarkdown } from 'fumadocs-core/server';

const text = await renderToMarkdown(
  <div>
    <h2>Hello World</h2>
    <p>
      Some <b>rich</b> content.
    </p>
  </div>,
);
```

```md tab="Output"
## Hello World

Some **rich** content.
```

[Remark LLMs](/docs/headless/mdx/remark-llms#jsx-elements) 所匯出的元件即以它為基礎，它也適用於任何您想以 Markdown 形式提供的伺服器端算繪內容。

> `renderToMarkdown()` 僅能在伺服器端使用。

## `asMarkdown` [#asmarkdown]

元件會自行定義其 Markdown 形式。在算繪期間呼叫 `asMarkdown()` 即代表選擇啟用此功能：當元件正被算繪為 Markdown 時，它會回傳[目標](#targets)，且元件所回傳的 HTML 元素會被轉換。

```tsx
import { asMarkdown, md } from 'fumadocs-core/server';

function Callout({ title, children }) {
  if (asMarkdown()) return md.linePrefix('> ')`**${title}**\n${children}`;

  return <div className="...">...</div>;
}
```

從未呼叫它的元件，會連同其 props 一併保留為 JSX 語法，例如：

```mdx
<Tabs items={['a', 'b']}>...</Tabs>
```

這包括不會在伺服器上執行的用戶端元件。

### 目標 [#targets]

樹狀結構會依目標進行算繪，目標由 `renderToMarkdown()` 的 `target` 選項指定：

* `markdown` (預設) ：提供給 AI 代理的文件。
* `search`：[搜尋紀錄](/docs/headless/mdx/structure#components)的文字。內容包含連結的文字，但不含圖片或程式碼區塊；沒有 Markdown 形式的元件則會輸出為 HTML 標籤，並帶有其文字 props。

這些規則適用於元件回傳的元素，例如 `<a href>`。若在 `md` 範本中以純文字撰寫連結，搜尋結果中仍會保留其連結目標，因此請直接回傳元素，或自行檢查目標。

`asMarkdown()` 會回傳目前的目標，讓元件能提供給 AI 代理比搜尋索引更多的內容：

```tsx
import { asMarkdown, md } from 'fumadocs-core/server';

function Version({ name, released }) {
  const target = asMarkdown();
  if (target === 'search') return name;
  if (target) return md`${name} (released ${released})`;

  return <span title={released}>{name}</span>;
}
```

## `md` [#md]

用於產生 Markdown 輸出的標籤範本 (tagged template) ，插值可以是字串、React 節點、Promise，或由它們組成的陣列。您可以先用它將 `children` 轉為字串，再進行處理。

以下兩種變體會將內容以區塊形式回傳：

* `md.linePrefix(prefix)`：為每一行加上前綴，例如引言區塊使用 `'> '`。
* `md.indent(size)`：將每一行縮排。

## `renderRoute` [#renderroute]

將頁面元素算繪為 Markdown；若其元件未呼叫 `asMarkdown()`，則回傳 `undefined`。

```tsx
import { renderRoute } from 'fumadocs-core/server';

const text = await renderRoute(<Page params={params} />);
```

適合用來提供路由的 Markdown 版本：有啟用此功能的頁面會產生 Markdown，其他頁面則回傳 `undefined`，讓您能改為回傳 404 或改用其他來源。
