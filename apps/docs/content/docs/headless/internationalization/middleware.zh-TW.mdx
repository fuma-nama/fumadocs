## 設定 [#setup]

此功能會將使用者重新導向至適當的語系，您可以在 `i18n.ts` 設定檔中自訂。

此功能透過 Next.js 的 Proxy 實作。若要在 React Router、TanStack Start、Waku 與 Astro 中進行設定，請參閱[國際化](/docs/internationalization)。

</include>

> 啟用 `hideLocale` 時，會使用 `NextResponse.rewrite` 隱藏語系前綴。
