## Setup

Redirects users to appropriate locale, it can be customized from `i18n.ts` config file.

It's a Next.js proxy. See [Internationalization](/docs/internationalization) for the setup on React Router, TanStack Start, Waku and Astro.

  ../../examples/i18n/proxy.ts
</include>

> When `hideLocale` is enabled, it uses `NextResponse.rewrite` to hide locale prefixes.
