## 簡介 [#introduction]

Trieve 整合會自動設定 Trieve Search，用於網站搜尋。

預設情況下，它會為文件中的**每個段落**各建立一個 chunk，這也是
Trieve 官方建議的做法。

## 設定 [#setup]

### 安裝相依套件 [#install-dependencies]

```package-install
trieve-ts-sdk trieve-fumadocs-adapter
```

### 註冊 Trieve [#sign-up-on-trieve]

請先註冊並建立一個資料集 (dataset) ，接著取得 2 組 API 金鑰：一組僅有讀取權限，另一組則具備管理員權限，可用來建立及刪除 chunk。
請將資料集 ID 與管理員金鑰存放在 `.env.local` 中，以便進行同步：

```dotenv
TRIEVE_DATASET_ID="dataset ID"
TRIEVE_ADMIN_API_KEY="admin API key"
```

<Callout title="注意">
  其中一組 API Key 應僅具備唯讀權限，供對外公開的搜尋使用；另一組則需具備
  管理員權限，用於建立及刪除 chunk。
</Callout>

### 同步資料集 [#sync-dataset]

Trieve 會沿用 [Algolia 整合](/docs/headless/search/algolia)的紀錄。請透過預先算繪的 `static.json` 路由匯出這些紀錄，並在每次建置後以指令碼將其同步至 Trieve：

<feature>search/trieve</feature>

`build` 指令碼會在每次建置時進行同步，因此請在您的部署平台上設定相同的變數。

### 搜尋 UI [#search-ui]

您可以使用對方提供的 `SearchDialog` 元件：

```tsx title="components/search.tsx"
'use client';
import type { SharedProps } from 'fumadocs-ui/components/dialog/search';
import SearchDialog from 'trieve-fumadocs-adapter/components/dialog/search';
import { TrieveSDK } from 'trieve-ts-sdk';

const trieveClient = new TrieveSDK({
  apiKey: 'readOnlyApiKey',
  datasetId: 'datasetId',
});

export default function CustomSearchDialog(props: SharedProps) {
  return <SearchDialog trieveClient={trieveClient} {...props} />;
}
```

1. 將 `apiKey` 和 `datasetId` 替換為您要使用的值。

2. 將預設的搜尋對話方塊替換為您新建立的版本。

### 搜尋用戶端 [#search-client]

加入 `useTrieveSearch` hook：

```ts
import { TrieveSDK } from 'trieve-ts-sdk';
import { useTrieveSearch } from 'trieve-fumadocs-adapter/search/trieve';

const client = new TrieveSDK({
  apiKey: 'readOnlyApiKey',
  datasetId: 'datasetId',
});

const { search, setSearch, query } = useTrieveSearch(client);
```

## 選項 [#options]

### 標籤篩選 [#tag-filter]

若要設定標籤篩選，請在索引中加入 `tag` 值。

```js
import { sync } from 'trieve-fumadocs-adapter/search/sync';
import { TrieveSDK } from 'trieve-ts-sdk';

const client = new TrieveSDK({
  apiKey: 'adminApiKey',
  datasetId: 'datasetId',
});

const documents = records.map((index) => ({
  ...index,
  tag: 'value', // [!code highlight]
}));

sync(client, documents);
```

#### 搜尋 UI [#search-ui-1]

啟用標籤篩選。

```tsx title="components/search.tsx"
import SearchDialog from 'trieve-fumadocs-adapter/components/dialog/search';

<SearchDialog
  defaultTag="value"
  tags={[
    {
      name: 'Tag Name',
      value: 'value',
    },
  ]}
/>;
```

#### 搜尋用戶端 [#search-client-1]

`tag_set` 欄位是用於篩選的屬性。若要依標籤篩選索引，請在 Trieve 搜尋用戶端中使用篩選功能。

```json
{
  "must": [
    {
      "field": "tag_set",
      "match": ["value"]
    }
  ]
}
```

或使用 `useTrieveSearch` hook：

```ts
import { TrieveSDK } from 'trieve-ts-sdk';
import { useTrieveSearch } from 'trieve-fumadocs-adapter/search/trieve';

const client = new TrieveSDK({
  apiKey: 'readOnlyApiKey',
  datasetId: 'datasetId',
});

const { search, setSearch, query } = useTrieveSearch(client, undefined, '<your tag value>');
```
