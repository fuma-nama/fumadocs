[Mixedbread](https://www.mixedbread.com) provides semantic search, users can search with natural language and find content by meaning rather than keywords.

## Setup

Install dependencies:

```package-install
@mixedbread/sdk
```

### API Key

Sign up at [Mixedbread](https://platform.mixedbread.com), create an [API key](https://platform.mixedbread.com/platform?next=api-keys) and a [store](https://platform.mixedbread.com/platform?next=stores) for your docs, and store them in `.env.local`:

```dotenv
MXBAI_API_KEY="your API key"
MIXEDBREAD_STORE_ID="your store ID"
```

Searching runs on your server, the API key is never exposed to the browser.

### Sync Documents

Pre-render a `static.json` route to export the search documents on build, and sync them to your store with a script after each build:

<feature>search/mixedbread</feature>

`sync()` uploads a file for each page, and skips the pages unchanged since the last sync. Files of removed pages are deleted, use a store dedicated to your docs. The `build` script syncs on every build, set the same variables on your deployment platform.

### Search API

Create a route to search your store:

```ts title="app/api/search/route.ts"
import { createMixedbreadSearchAPI } from 'fumadocs-core/search/mixedbread';
import Mixedbread from '@mixedbread/sdk';

export const { GET } = createMixedbreadSearchAPI({
  client: new Mixedbread(), // reads `MXBAI_API_KEY`
  storeIdentifier: process.env.MIXEDBREAD_STORE_ID!,
});
```

### Search UI

You can consider different options for implementing the UI:

- Using [Fumadocs UI search dialog](/docs/search/mixedbread).
- Build your own using the built-in search client hook:

  ```ts twoslash
  import { useFetchSearch } from 'fumadocs-core/search/client';

  const { search, onSearchChange, isLoading, data } = useFetchSearch({
    api: '/api/search',
    // every search is a request to Mixedbread
    delayMs: 300,
  });
  ```

## Options

### Tag Filter

To configure tag filtering, pass a `tag` to `toDocuments()` in the `static.json` route:

```ts
toDocuments(source, { tag: (page) => page.slugs[0] });
```

And update your search client:

- **Fumadocs UI**: Enable [Tag Filter](/docs/search/mixedbread#tag-filter) on Search UI.
- **Search Client**: pass a tag to `useFetchSearch()`.

  ```ts
  import { useFetchSearch } from 'fumadocs-core/search/client';

  const { search, onSearchChange, isLoading, data } = useFetchSearch({
    tag: '<your tag value>', // [!code ++]
    // ...
  });
  ```

### Internationalization

Documents include the locale of their pages, pass `locale` to search in a language:

```ts
import { useI18n } from 'fumadocs-ui/contexts/i18n';
import { useFetchSearch } from 'fumadocs-core/search/client';

const { locale } = useI18n();
const { search, onSearchChange, isLoading, data } = useFetchSearch({
  locale, // [!code ++]
  // ...
});
```

## Under the Hood

Each page is a file keyed by its URL, with the page title, URL, breadcrumbs, tags and locale as metadata. Its chunks are the title, headings and paragraphs of the page, every result is a chunk:

| Chunk Metadata | Description                                |
| -------------- | ------------------------------------------ |
| `kind`         | `page`, `heading` or `text`                |
| `heading`      | ID of the heading it belongs to (optional) |
| `table`        | Table of a table row (optional)            |
