title: Remark Structure
description: Extract search records from your documents.
---

The `remarkStructure` plugin extracts the headings and contents of a document as records for [search](/docs/headless/search). Records keep the Markdown you wrote, see [Stringification](/docs/headless/mdx/stringification) for how it's generated.

```mdx tab="Input"
## Installation

Run the [command](/docs/cli) below.

<Callout>Restart the **server** after it.</Callout>

| Option | Default |
| ------ | ------- |
| `dir`  | `docs`  |
```

```json tab="Output"
{
  "headings": [{ "id": "installation", "content": "Installation" }],
  "contents": [
    { "heading": "installation", "content": "Run the command below." },
    { "heading": "installation", "content": "<Callout>Restart the **server** after it.</Callout>" },
    {
      "heading": "installation",
      "content": "| Option | Default |\n| --- | --- |\n| `dir` | `docs` |",
      "table": "table-0"
    }
  ]
}
```

## Usage

```ts title="source.config.ts" tab="Fumadocs MDX"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    // enabled by default, exported as `structuredData`
    remarkStructureOptions: {},
  },
});
```

```ts tab="MDX Compiler"
import { compile } from '@mdx-js/mdx';
import { remarkStructure } from 'fumadocs-core/mdx-plugins';

const file = await compile('...', {
  // `exportAs` exports it from the document too
  remarkPlugins: [[remarkStructure, { exportAs: 'structuredData' }]],
});

console.log(file.data.structuredData);
```

## Records

Headings, paragraphs, blockquotes, tables and JSX elements are recorded (see `types`):

- Links are replaced by their text, images are removed.
- A table has a record per row, as a table of its header and that row. The rows share a `table` field.
- JSX elements are replaced by their content, except those kept as HTML tags by `filterElement`, which search dialogs render as components.
- A JSX element is a record when it has no children (see `mdxTypes`), or fits on one line.
- Content inside a record isn't recorded again.

By default, `File`, `TypeTable`, `Callout` and `Card` are kept as HTML tags:

```ts title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    remarkStructureOptions: {
      filterElement: (node) => node.name === 'Callout' || node.name === 'Banner',
    },
  },
});
```

## Plugins

Nodes inserted by plugins aren't recorded, a plugin adds the records of its node with `data.structuredData`:

```ts
node.data = {
  ...node.data,
  structuredData: {
    // `heading` defaults to the current heading
    contents: [{ heading: undefined, content: 'Generated **content**' }],
  },
};
```

## As a Function

```ts
import { structure } from 'fumadocs-core/mdx-plugins';
import remarkMath from 'remark-math';

// with the remark plugins your content needs
const data = structure(content, [remarkMath], options);
```
