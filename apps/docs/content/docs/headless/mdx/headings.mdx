## Remark Heading

A remark plugin that applies ids to headings. Fumadocs MDX enables it by default. Pass options with `remarkHeadingOptions`.

By default, ids are slugged from the source. With the `analysis: 'runtime'` option, headings with expressions, like `## Deploy on {props.framework}`, and headings inside `<show>` get their ids when rendering, from their rendered text. Duplicate ids then only count the headings that show. Fumadocs MDX passes the [`analysis`](/docs/mdx/collections#analysis) of the collection.

### Custom Ids [#custom-heading-id]

You can customize the heading id with `[#slug]`.

```md
# heading [#slug]
```

To disable it:

```ts tab="unified" title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    remarkHeadingOptions: {
      customId: false,
    },
  },
});
```

```ts tab="Sätteri" title="source.config.ts"
import { defineConfig, defineDocs } from 'fumadocs-mdx/config';

export const docs = defineDocs({
  docs: { compiler: 'satteri' },
});

export default defineConfig({
  satteriOptions: {
    remarkHeadingOptions: {
      customId: false,
    },
  },
});
```

### Extract TOC

By default, it also extracts the headings (table of contents) of a document to the file data as `toc`, an array of `TOCItemType`.
Fumadocs MDX turns it off with `generateToc: false` and exports the table of contents with [Rehype TOC](#rehype-toc) instead.

## Rehype TOC

A rehype plugin that exports the table of contents. Unlike Remark Heading, it keeps JSX nodes in heading titles.

Fumadocs MDX enables it by default. On Sätteri, pass options with `rehypeTocOptions`.

### Output

For a Markdown document:

```md
## Hello `code`
```

It exports an array of `TOCItemType`. With the `analysis: 'runtime'` option, it exports a function of the page's props, returning only the headings in `<show>` branches that show:

```jsx tab="static"
export const toc = [
  {
    title: (
      <>
        Hello <code>code</code>
      </>
    ),
    depth: 2,
    url: '#hello-code',
  },
];
```

```jsx tab="runtime"
export const toc = (props) => [
  {
    title: (
      <>
        Hello <code>code</code>
      </>
    ),
    depth: 2,
    url: '#hello-code',
  },
];
```

Fumadocs MDX passes the [`analysis`](/docs/mdx/collections#analysis) of the collection. With `runtime`, `page.data.toc()` calls the export with the path params of the page.
