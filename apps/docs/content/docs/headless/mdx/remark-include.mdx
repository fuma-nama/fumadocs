## Usage

Remark Include is a remark plugin. Fumadocs MDX enables it by default on both unified and Sätteri. See [Include](/docs/mdx/include) for the syntax.

Paths are relative to the compiled file. On unified, included Markdown & MDX files are parsed by the current processor unless you pass `getProcessor`. Fumadocs MDX passes it, so each file is parsed by its own format.
