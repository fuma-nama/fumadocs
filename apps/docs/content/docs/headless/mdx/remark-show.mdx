title: Remark Show

## Usage

Remark Show is a remark plugin that compiles [`<show>`](/docs/markdown#show) into a component. Fumadocs MDX, `@fumadocs/astro` and [Local Markdown](/docs/integrations/content/local-md) enable it by default.

The component renders its content when `when` holds. The condition is checked when rendering, so it can read the props of the page, like its [path params](/docs/headless/page-conventions#path-params). A `<show>` without `when` fails to compile.

## Outputs

The table of contents, [heading IDs](/docs/headless/mdx/headings#headings-with-expressions), [structured data](/docs/headless/mdx/structure) and [processed Markdown](/docs/headless/mdx/remark-llms) of a page only include the branches that show for its props.

<Callout type="warn">
  Used on their own, Rehype TOC, Remark Structure and Remark LLMs analyse the source before any
  condition is checked, so with Remark Show, a document with `<show>` fails to compile. A custom
  content source asks for [runtime outputs](/docs/headless/source-api/source#runtime-outputs)
  instead.
</Callout>

## Steps and Tab Groups

A step inside `<show>` is one of the steps around it, and a code block inside `<show>` is a tab of the [tab group](/docs/markdown#tab-groups) around it. Remark Show has to run before [Remark Steps](/docs/headless/mdx/remark-steps) and `remarkCodeTab`.

When every step or tab is inside a `<show>`, each `<show>` has its own steps or tab group.
