## Usage

Remark Show is a remark plugin. Fumadocs MDX and `@fumadocs/astro` enable it by default on both unified and Sätteri. See [Show](/docs/markdown#show) for the syntax.

It turns `<show>` into a component that renders its content when `when` holds. Conditions are checked when rendering, so they can read the props of a page, like its path params. The other plugins of Fumadocs output the branches as conditions too: the table of contents, structured data and Markdown of a page only include the branches that show.

### Custom Sources

A [custom source](/docs/headless/source-api/source#path-params) that compiles MDX compiles each file once and passes the params of a page as props when rendering. When a page reads its props, in a branch or an expression like `{props.framework}`, the `toc` and `structuredData` exports are functions of the props. Call them with the params of the page:

```ts twoslash
import type { Params } from 'fumadocs-core/source';
import type { TOCItemType } from 'fumadocs-core/toc';

declare const params: Params;
declare const compiled: { toc: TOCItemType[] | ((props: Params) => TOCItemType[]) };
// ---cut---
const toc = typeof compiled.toc === 'function' ? compiled.toc(params) : compiled.toc;
```

The content of their structured data records can be React nodes, render them into text with `renderToMarkdown()` from `fumadocs-core/server`.
