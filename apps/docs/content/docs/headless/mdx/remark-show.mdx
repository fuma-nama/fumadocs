## Usage

Remark Show is a remark plugin. Fumadocs MDX and `@fumadocs/astro` enable it by default on both unified and Sätteri. See [Show](/docs/markdown#show) for the syntax.

It compiles `<show>` into a component that renders its content when `when` holds. The condition is checked when rendering, so it can read the props of the page, like its [path params](/docs/headless/page-conventions#path-params). A `<show>` without `when` fails to compile.

## Outputs

The outputs of a page, which are its table of contents, [heading IDs](/docs/headless/mdx/headings), [structured data](/docs/headless/mdx/structure) and [processed Markdown](/docs/headless/mdx/remark-llms), only include the branches that show. Fumadocs MDX, `@fumadocs/astro` and [local Markdown](/docs/integrations/content/local-md) render them for the props of each page.

<Callout type="warn">
  Used on their own, Rehype TOC, Remark Structure and Remark LLMs give static outputs, which are analysed from the source before any condition is checked. A document with `<show>` then fails to compile, unless a custom content source asks for [runtime outputs](/docs/headless/source-api/source#runtime-outputs).
</Callout>
