---
title: Remark LLMs
description: Export the Markdown of your documents for LLMs.
---

The `remarkLLMs` plugin exports the Markdown of a document as `_markdown`, for LLMs. It keeps the Markdown you wrote, see [Stringification](/docs/headless/mdx/stringification) for how it's generated.

```mdx tab="Input"
import { Callout } from 'fumadocs-ui/components/callout';

## Getting Started

<Callout>Hello **world**.</Callout>
```

```md tab="Output"
## Getting Started [#getting-started]

<Callout>Hello **world**.</Callout>
```

ESM is removed, headings get their IDs (see `headingIds`), and included content is expanded with Fumadocs MDX.

## Usage

```ts title="source.config.ts" tab="Fumadocs MDX"
import { defineDocs } from 'fumadocs-mdx/config';

export default defineDocs({
  docs: {
    postprocess: {
      // `true`, or the options of `remarkLLMs`
      includeProcessedMarkdown: true,
    },
  },
});
```

```ts tab="MDX Compiler"
import { compile } from '@mdx-js/mdx';
import { remarkLLMs } from 'fumadocs-core/mdx-plugins/remark-llms';

await compile('...', {
  remarkPlugins: [remarkLLMs],
});
```

With Fumadocs MDX, read it from your pages:

```ts
const markdown = await page.data.getText('processed');
```

## JSX Elements

JSX elements are kept as you wrote them. To change them:

| Option               | Elements                                      |
| -------------------- | --------------------------------------------- |
| `filterElement`      | Removed, or replaced by their children        |
| `mdxAsPlaceholder`   | Turned into placeholders, rendered at runtime |
| `output: 'function'` | Rendered by their components, into Markdown   |

### Placeholders

List the components to output as placeholders:

```ts
import type { LLMsOptions } from 'fumadocs-core/mdx-plugins/remark-llms';

const llmsOptions: LLMsOptions = {
  mdxAsPlaceholder: ['Callout'],
};
```

Then render them, from runtime data if needed:

```ts
import { renderPlaceholder } from 'fumadocs-core/mdx-plugins/remark-llms.runtime';

const markdown = await renderPlaceholder(await page.data.getText('processed'), {
  // `children` is the Markdown of its content
  Callout: ({ attributes, children }) => `> **${attributes.title}**\n>\n> ${children}`,
});
```

### Function Output [#output]

With `output: 'function'`, `_markdown` is a component: Markdown stays as you wrote it, JSX elements are rendered by your components.

```ts
import type { LLMsOptions } from 'fumadocs-core/mdx-plugins/remark-llms';

const llmsOptions: LLMsOptions = {
  output: 'function',
};
```

Render it with your components:

```tsx tab="Fumadocs MDX"
import { getMDXComponents } from '@/components/mdx';

const markdown = await page.data.getText('processed', {
  components: getMDXComponents(),
});
```

```tsx tab="MDX Compiler"
import { renderToMarkdown } from 'fumadocs-core/server';
import { getMDXComponents } from '@/components/mdx';
import { _markdown as Markdown } from './page.mdx';

const markdown = await renderToMarkdown(<Markdown components={getMDXComponents()} />);
```

Components define their Markdown form with `asMarkdown()`, others are kept as JSX, see [Markdown Rendering](/docs/headless/utils/markdown).
