## 概覽 [#overview]

請在 {frameworkName(props.framework)} 與 Fumadocs 兩端設定 i18n 路由。

Fumadocs 會負責文件內容與側邊欄的 i18n。應用程式的其他部分，請透過您自己的 i18n 設定來進行國際化。

<show when={props.framework === 'next'}>
  您也可以搭配 Fumadocs 使用 [next-intl](https://github.com/amannn/next-intl) 等函式庫。如需了解基本概念，請參閱 [Next.js 的 i18n](https://nextjs.org/docs/app/building-your-application/routing/internationalization)。
</show>

### 搜尋 [#search]

請在您使用的搜尋方案中設定 i18n。

* **內建搜尋：** 請參閱[國際化](/docs/headless/search/orama#internationalization)。
* **雲端方案 (例如 Algolia) ：** 這類方案通常有官方的多語系支援。

## 撰寫文件 [#writing-documents]

請參閱 [i18n 路由](/docs/page-conventions#i18n-routing)，了解如何為特定語系建立頁面。

### 導覽 [#navigation]

Fumadocs 只會處理其自身版面配置 (例如側邊欄) 中的導覽。
