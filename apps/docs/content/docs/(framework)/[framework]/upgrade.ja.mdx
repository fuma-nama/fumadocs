Fumadocs のパッケージはすべてまとめてアップグレードしてください。Fumadocs UI は、同時にリリースされたバージョンと完全に一致する `fumadocs-core` をピア依存関係として必要とします。

以下のコマンドは、すべての `fumadocs-*` および `@fumadocs/*` パッケージをアップグレードします。また、テンプレートで使用されている `fumadocs-ui` から `@fumadocs/base-ui` へのエイリアスもそのまま維持されます。

```bash tab="npm"
npx npm-check-updates -u "fumadocs-*" "@fumadocs/*" && npm install
```

```bash tab="pnpm"
pnpm update --latest "fumadocs-*" "@fumadocs/*"
```

```bash tab="yarn"
npx npm-check-updates -u "fumadocs-*" "@fumadocs/*" && yarn install
```

```bash tab="bun"
bun update --latest "fumadocs-*" "@fumadocs/*"
```

`yarn up` を使うとエイリアスが Radix UI 版の `fumadocs-ui` に置き換えられてしまうため、Yarn のコマンドでは npm-check-updates を使用しています。

## メジャーバージョン [#major-versions]

メジャーバージョンをまたいでアップグレードする際は、該当するバージョンのリリースノートを確認してください。

* [Fumadocs 16](/blog/v16): 15.2 から非推奨となっていた API を削除し、`fumadocs-core/server` のエクスポートを個別のモジュールに移動しました。また、React 19.2 が必要になりました。
* [Fumadocs 15](/blog/v15): スタイルを Tailwind CSS v4 に移行しました。
