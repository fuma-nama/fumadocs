## 設定 [#setup]

Fumadocs CLI 可以幫您完成設定，它會建立搜尋對話方塊、`static.json` 路由，以及一個在每次建置後同步搜尋索引的指令碼：

```package-install
npx @fumadocs/cli feature search --provider orama-cloud
```

或手動設定：

1. 整合 [Orama Cloud](/docs/headless/search/orama-cloud)。

2. 建立搜尋對話方塊，並將 `endpoint` 與 `api_key` 替換為您要使用的值。
