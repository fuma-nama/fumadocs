## 概要 [#overview]

Fumadocs では、[ZBSearch 検索エンジン](/docs/headless/search/orama)が標準で設定されています。

検索は、サーバー上で動作する API エンドポイント経由で行われます。静的サイトの場合は、静的にキャッシュされた JSON ファイルを利用して検索します。

## セットアップ [#setup]

検索ダイアログを作成します。
