## セットアップ [#setup]

Fumadocs CLI を使うと、セットアップを自動で行えます。検索ダイアログ、`static.json` ルート、ビルドのたびに検索インデックスを同期するスクリプトが作成されます。

```package-install
npx @fumadocs/cli feature search --provider meilisearch
```

または、手動で設定することもできます。

1. [Meilisearch](/docs/headless/search/meilisearch) を統合します。

2. 検索ダイアログを作成し、`host` と `apiKey` をお使いのホスト URL と検索用 API キーに置き換えます。

### タグフィルター [#tag-filter]

必要に応じて、検索結果をタグで絞り込むための UI を追加できます。ドキュメントに[タグフィルター](/docs/headless/search/meilisearch#tag-filter)を設定したうえで、以下を追加してください。

```tsx
'use client';

import {
  SearchDialog,
  SearchDialogContent,
  SearchDialogFooter,
  SearchDialogOverlay,
  type SharedProps,
  TagsList,
  TagsListItem,
} from 'fumadocs-ui/components/dialog/search';
import { useState } from 'react';
import { useMeilisearch } from 'fumadocs-core/search/client';

export default function CustomSearchDialog(props: SharedProps) {
  // [!code ++]
  const [tag, setTag] = useState<string | undefined>();
  const search = useMeilisearch({
    tag, // [!code ++]
    // その他のオプション...
  });

  return (
    <SearchDialog {...search} {...props}>
      <SearchDialogOverlay />
      <SearchDialogContent>
        ...
        <SearchDialogFooter className="flex flex-row">
          {/* [!code ++:3] */}
          <TagsList tag={tag} onTagChange={setTag}>
            <TagsListItem value="my-value">My Value</TagsListItem>
          </TagsList>
        </SearchDialogFooter>
      </SearchDialogContent>
    </SearchDialog>
  );
}
```
