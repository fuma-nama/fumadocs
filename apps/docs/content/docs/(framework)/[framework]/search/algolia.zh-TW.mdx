## 概覽 [#overview]

設定指南請參閱[整合 Algolia 搜尋](/docs/headless/search/algolia)。

雖然我們一般建議您使用 Algolia 的用戶端 SDK 自行建構搜尋功能，
但您也可以直接套用內建的搜尋對話方塊介面。

## 設定 [#setup]

Fumadocs CLI 可以自動幫您完成設定，包括建立搜尋對話方塊、`static.json` 路由，以及在每次建置後同步搜尋索引的指令碼：

```package-install
npx @fumadocs/cli feature search --provider algolia
```

或手動設定：

建立搜尋對話方塊，並將 `appId`、`apiKey` 和 `indexName` 替換為您需要的值。
