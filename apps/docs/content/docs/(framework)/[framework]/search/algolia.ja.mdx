## 概要 [#overview]

セットアップ方法については、[Algolia Searchとの連携](/docs/headless/search/algolia)を参照してください。

一般的には、Algoliaのクライアントサイド
SDKを使って独自の検索を構築することをおすすめしますが、組み込みの検索ダイアログを利用することもできます。

## セットアップ [#setup]

Fumadocs CLI を使うと、セットアップを自動で行えます。検索ダイアログ、`static.json` ルート、およびビルドのたびに検索インデックスを同期するスクリプトが作成されます。

```package-install
npx @fumadocs/cli feature search --provider algolia
```

または、手動で設定することもできます。

検索ダイアログを作成し、`appId`、`apiKey`、`indexName` を任意の値に置き換えてください。
