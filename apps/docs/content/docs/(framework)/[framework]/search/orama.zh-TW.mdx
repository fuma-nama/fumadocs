## 概覽 [#overview]

Fumadocs 預設已設定好 [ZBSearch 搜尋引擎](/docs/headless/search/orama)，開箱即用。

搜尋會透過伺服器上執行的 API 端點進行；若是靜態網站，則改用靜態快取的 JSON 檔案。
