## セットアップ [#setup]

Mixedbread 検索はリクエスト時にサーバー上で実行されるため、静的サイトでは利用できません。

Fumadocs CLI を使えば、セットアップを自動で行えます。検索ダイアログ、検索ルート、`static.json` ルートに加え、ビルドのたびにストアを同期するスクリプトが作成されます。

```package-install
npx @fumadocs/cli feature search --provider mixedbread
```

または、手動で設定する場合:

1. [Mixedbread Search](/docs/headless/search/mixedbread) を統合します。

2. 検索ダイアログのコンポーネントを作成します。
