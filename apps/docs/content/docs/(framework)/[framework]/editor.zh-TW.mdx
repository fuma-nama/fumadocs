## 簡介 [#introduction]

[Fumadocs Editor](https://editor.fumadocs.dev) 是一款專為 Fumadocs MDX 打造的視覺化編輯器。

### 從 Studio 開始 [#start-with-studio]

Studio 會在瀏覽器中開啟您的本機文件，無須在應用程式中加入編輯器。
請在您的 Fumadocs 專案中執行：

```bash
npx @fumadocs-editor/studio
```

Studio 需要 **Node.js 24 或更新版本**。它會尋找 `content/docs`，若找不到，則改為在上層目錄中尋找。
若要指定其他內容資料夾：

```bash
npx @fumadocs-editor/studio --root ./docs
```

編輯內容會自動儲存到磁碟，您在程式碼編輯器中所做的變更也會合併到目前開啟的文件中。
檔案清單會依照您的 `meta.json` 排序。

請在 Git 中檢閱變更，再透過網站平常使用的部署流程發布。

> Studio 僅能編輯既有檔案。如需建立、重新命名或刪除檔案，請改用程式碼編輯器或檔案管理員。

### 使用元件撰寫 [#write-with-components]

內建編輯支援涵蓋 Callout、Cards、Steps、Accordions 與 Files 等 Fumadocs 元件。

自訂元件可透過[元件規格](https://editor.fumadocs.dev/components)定義各自的可編輯區域。

<Callout title="保留您現有的內容設定">
  編輯器直接處理您的 Markdown 與 MDX 檔案。您可以繼續使用 [Fumadocs MDX](/docs/mdx) 載入
  這些檔案，並以您的 React 框架算繪發布的網站。
</Callout>
