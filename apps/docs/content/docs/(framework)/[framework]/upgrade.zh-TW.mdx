請一併升級所有 Fumadocs 套件。Fumadocs UI 將 `fumadocs-core` 設為 peer dependency，且版本必須與其發布時所搭配的版本完全一致。

以下指令會升級所有 `fumadocs-*` 與 `@fumadocs/*` 套件，並保留範本所使用的 `fumadocs-ui` 別名 (指向 `@fumadocs/base-ui`) ：

```bash tab="npm"
npx npm-check-updates -u "fumadocs-*" "@fumadocs/*" && npm install
```

```bash tab="pnpm"
pnpm update --latest "fumadocs-*" "@fumadocs/*"
```

```bash tab="yarn"
npx npm-check-updates -u "fumadocs-*" "@fumadocs/*" && yarn install
```

```bash tab="bun"
bun update --latest "fumadocs-*" "@fumadocs/*"
```

Yarn 指令改用 npm-check-updates，因為 `yarn up` 會把別名替換成 Radix UI 版本的 `fumadocs-ui`。

## 主要版本 [#major-versions]

升級跨越主要版本時，請閱讀該版本的發行說明：

* [Fumadocs 16](/blog/v16)：移除自 15.2 起已棄用的 API，將 `fumadocs-core/server` 的匯出移至各自對應的模組，並需要 React 19.2。
* [Fumadocs 15](/blog/v15)：將樣式遷移至 Tailwind CSS v4。
