請同時升級所有 Fumadocs 套件。Fumadocs UI 會將其發布時搭配的 `fumadocs-core` 確切版本列為 peer dependency。

以下指令會升級所有 `fumadocs-*` 與 `@fumadocs/*` 套件，並保留範本所使用、指向 `@fumadocs/base-ui` 的 `fumadocs-ui` 別名：

```bash tab="npm"
npx npm-check-updates -u "fumadocs-*" "@fumadocs/*" && npm install
```

```bash tab="pnpm"
pnpm update --latest "fumadocs-*" "@fumadocs/*"
```

```bash tab="yarn"
npx npm-check-updates -u "fumadocs-*" "@fumadocs/*" && yarn install
```

```bash tab="bun"
bun update --latest "fumadocs-*" "@fumadocs/*"
```

Yarn 的指令改用 npm-check-updates，因為 `yarn up` 會把別名替換成 Radix UI 版本的 `fumadocs-ui`。
