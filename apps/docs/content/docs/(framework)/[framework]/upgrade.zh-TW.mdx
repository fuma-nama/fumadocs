請同時升級所有 Fumadocs 套件。Fumadocs UI 以 peer dependency 的形式，依賴其發布時所搭配的特定 `fumadocs-core` 版本。

以下指令會升級所有 `fumadocs-*` 與 `@fumadocs/*` 套件，並保留範本中指向 `@fumadocs/base-ui` 的 `fumadocs-ui` 別名：

```bash tab="npm"
npx npm-check-updates -u "fumadocs-*" "@fumadocs/*" && npm install
```

```bash tab="pnpm"
pnpm update --latest "fumadocs-*" "@fumadocs/*"
```

```bash tab="yarn"
npx npm-check-updates -u "fumadocs-*" "@fumadocs/*" && yarn install
```

```bash tab="bun"
bun update --latest "fumadocs-*" "@fumadocs/*"
```

Yarn 指令改用 npm-check-updates，因為 `yarn up` 會把別名替換成 Radix UI 版本的 `fumadocs-ui`。

## 主要版本 [#major-versions]

* [Fumadocs 15](/blog/v15)：將樣式遷移至 Tailwind CSS v4。
