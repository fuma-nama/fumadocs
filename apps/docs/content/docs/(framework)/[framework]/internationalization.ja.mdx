## 概要 [#overview]

{frameworkName(props.framework)} と Fumadocs の両方で i18n ルーティングを設定します。

Fumadocs が担当するのは、ドキュメントのコンテンツとサイドバーの i18n です。アプリのその他の部分は、独自の i18n 設定で国際化してください。

<show when={props.framework === 'next'}>
  [next-intl](https://github.com/amannn/next-intl) などのライブラリを Fumadocs と組み合わせて使うこともできます。基本については、[Next.js の i18n](https://nextjs.org/docs/app/building-your-application/routing/internationalization) を参照してください。
</show>


  ```tsx tab="src/components/provider.tsx"
  import { navigate } from 'astro:transitions/client';
  import type { ReactNode } from 'react';
  import { RootProvider } from 'fumadocs-ui/provider/astro';
  // [!code ++:2]
  import { i18nProvider } from 'fumadocs-ui/i18n';
  import { translations } from '@/lib/layout.shared';
  import SearchDialog from '@/components/search';

  export interface ProviderProps {
    lang: string; // [!code ++]
    pathname: string;
    params: Record<string, string | undefined>;
    children?: ReactNode;
  }

  export function Provider({ lang, pathname, params, children }: ProviderProps) {
    return (
      <RootProvider
        pathname={pathname}
        params={params}
        navigate={navigate}
        // [!code ++]
        i18n={i18nProvider(translations, lang)}
        search={{ SearchDialog }}
      >
        {children}
      </RootProvider>
    );
  }

  // [!code ++:16]
  /**
   * MDX コンテンツ用(それ自体が独立したアイランドのため)。
   */
  export function ContentProvider({ lang, pathname, params, children }: ProviderProps) {
    return (
      <RootProvider
        pathname={pathname}
        params={params}
        navigate={navigate}
        i18n={i18nProvider(translations, lang)}
        theme={{ enabled: false }}
        search={{ enabled: false }}
      >
        {children}
      </RootProvider>
    );
  }
  ```

### 検索 [#search]

使用している検索ソリューションで i18n を設定してください。

* **組み込み検索:** [国際化](/docs/headless/search/orama#internationalization)を参照してください。
* **クラウドソリューション(Algolia など):** 多くの場合、多言語対応が公式にサポートされています。

## ドキュメントの作成 [#writing-documents]

特定のロケール向けのページを作成する方法については、[i18n ルーティング](/docs/page-conventions#i18n-routing)を参照してください。

### ナビゲーション [#navigation]

Fumadocs がナビゲーションを処理するのは、Fumadocs 自身のレイアウト(サイドバーなど)のみです。
