---
title: Obsidian
description: Obsidian の Vault を Fumadocs で直接レンダリングします。
---

`fumadocs-obsidian` はランタイムで動作するコンテンツソースを提供します。Vault を直接読み込んでコンパイルするため、中間 MDX ファイルを生成せず、Fumadocs MDX の remark プラグインも不要です。

サポートしている Obsidian の構文は次のとおりです。

* ウィキリンクと埋め込み
* コールアウト
* ブロック ID
* コメント

名前が曖昧なウィキリンクは、Obsidian と同じ規則で解決されます。ノートが添付ファイルより優先され、次にパスが最も短いものが優先されます。未知の言語のコードフェンス (例: `dataview`) はプレーンテキストとしてレンダリングされます。

## セットアップ [#setup]

パッケージをインストールします。

```package-install
fumadocs-obsidian shiki
```

### スタイルの生成 [#generate-styles]

`fumadocs-obsidian/ui` のコンポーネントは Tailwind CSS でスタイリングされています。これらのクラスが生成されるよう、次の行を追加してください。

```css title="Tailwind CSS"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
/* [!code ++] */
@import 'fumadocs-obsidian/css/preset.css';
```

### ソースの設定 [#configure-source]

Obsidian のソースを作成し、`dynamicLoader()` に渡します。

```ts title="lib/source.ts"
import { dynamicLoader } from 'fumadocs-core/source';
import { obsidian } from 'fumadocs-obsidian';

const vault = obsidian({
  dir: 'public/vault',
  // Vault の添付ファイルを公開 URL にマッピングします
  url: (path) => `/vault/${path}`,
});

const vaultLoader = dynamicLoader(vault.dynamicSource(), {
  baseUrl: '/docs',
});

export function getSource() {
  return vaultLoader.get();
}
```

この例ではVaultを `public/vault` に配置しているため、`url` が返すURLでフレームワークが添付ファイルを配信できます。アプリ側で添付ファイルを別途配信またはアップロードする場合は、Vaultを別の場所に配置してもかまいません。

次に、ページを読み込んでレンダリングします。`page.data.load()` は、コンパイル済みページのレンダラーを返します。

  ```tsx title="app/routes/docs.tsx"
  import type { Route } from './+types/docs';
  import { useMemo } from 'react';
  import { DocsLayout } from 'fumadocs-ui/layouts/docs';
  import { DocsBody, DocsPage } from 'fumadocs-ui/layouts/docs/page';
  import defaultMdxComponents from 'fumadocs-ui/mdx';
  import { useFumadocsLoader } from 'fumadocs-core/source/client';

  export async function loader({ params }: Route.LoaderArgs) {
    const source = await getSource();
    const page = source.getPage(params['*'].split('/').filter((v) => v.length > 0));
    if (!page) throw new Response('Not found', { status: 404 });

    return {
      // 構文木（クライアントでレンダリングされます）
      render: (await page.data.load()).serialize(),
      pageTree: await source.serializePageTree(source.getPageTree()),
    };

    const { render, pageTree } = useFumadocsLoader(loaderData);
    const renderer = useMemo(() => rendererFromSerialized(render), [render]);
    const { body, toc } = renderer.renderSync({ ...defaultMdxComponents, ...ObsidianComponents });

    return (
      <DocsLayout tree={pageTree}>
        <DocsPage toc={toc}>
          <DocsBody>{body}</DocsBody>
        </DocsPage>
      </DocsLayout>
    );
  }
  ```

`page.data.load()` は、Vault のスナップショットごとに各ページを最大1回だけコンパイルします。Vault のコンテンツはプレーンな Markdown としてコンパイルされ、レンダリング時には JSX へのマッピングとコンポーネント名の解決しか行わないため、コンテンツ内の JavaScript が実行されることはありません。メディアファイルは URL で参照されるため、メモリに読み込まれることはありません。

## 静的ソース [#static-source]

vault を一度だけ読み込めばよい場合は、`staticSource()` を使用します。

```ts title="lib/source.ts"
import { loader } from 'fumadocs-core/source';
import { obsidian } from 'fumadocs-obsidian';

const vault = obsidian({
  dir: 'public/vault',
  url: (path) => `/vault/${path}`,
});

export const source = loader(await vault.staticSource(), {
  baseUrl: '/docs',
});
```

## スキーマ [#schema]

Standard Schema 互換のバリデーターを使って、ページのフロントマターと `meta.json` ファイルをカスタマイズできます。

```ts title="lib/source.ts"
import { frontmatterSchema, obsidian } from 'fumadocs-obsidian';
import { metaSchema } from 'fumadocs-core/source/schema';
import { z } from 'zod';

const vault = obsidian({
  dir: 'public/vault',
  frontmatterSchema: frontmatterSchema.extend({
    tags: z.array(z.string()).optional(),
  }),
  metaSchema,
});
```

デフォルトの `frontmatterSchema` は、構造が緩い Vault にも柔軟に対応します。`title: 2024` のようなスカラー値のタイトルは文字列に変換され、`aliases` には単一の名前とリストのどちらも指定できます。検証に失敗したノートは報告されたうえでスキップされ、Vault 内の他のノートには影響しません。

### 追加機能 [#additions]

remark/rehype プラグインを渡すと、構文機能を個別に有効にできます。

* [Mermaid](/docs/markdown/mermaid)
* [数式](/docs/markdown/math)

```ts title="lib/source.ts"
import { obsidian } from 'fumadocs-obsidian';
import remarkMath from 'remark-math';
import rehypeKatex from 'rehype-katex';

const vault = obsidian({
  dir: 'public/vault',
  remarkPlugins: [remarkMath],
  rehypePlugins: [rehypeKatex],
});
```
