## はじめに [#introduction]

**Fumadocs は非常に柔軟です。** 公式のアダプターがなくても、どのようなコンテンツソースとも統合できます。

### 例 [#examples]

Fumadocs を CMS と組み合わせて使用する例を紹介します。CMS を使うと、コンテンツを快適に公開でき、アプリを再ビルドすることなくリアルタイムで更新を反映できます。

* [BaseHub](https://github.com/fuma-nama/fumadocs-basehub)
* [Sanity](https://github.com/fuma-nama/fumadocs-sanity)
* [コミュニティ: `MFarabi619` による Payload CMS](https://github.com/MFarabi619/fumadocs-payloadcms)
* [コミュニティ: `bapspatil` による Payload CMS](https://github.com/bapspatil/fumadocs-payload-template)

これでは足りない場合は、[独自のコンテンツソースを構築](/docs/integrations/content/custom)することもできます。
