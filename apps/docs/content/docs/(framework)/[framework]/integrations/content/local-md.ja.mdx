## はじめに [#introduction]

`@fumadocs/local-md` は、ローカルの Markdown/MDX ファイル向けのコンテンツソースです。設計上バンドラーを使用しないため、ランタイムのみで完結して動作します。

[MDX Remote](/docs/integrations/content/mdx-remote) と比べると、ローカルファイルに特化している分、パイプラインのより多くの部分(フロントマター、meta ファイル、検索インデックスの作成)を担います。

<show when={props.framework !== 'astro'}>
  [Fumadocs MDX](/docs/mdx) と比べると、型生成やバンドラーなしで動作しますが、ビルド時の画像最適化は無効になります。
</show>

<show when={props.framework === 'astro'}>
  Astro のコンテンツコレクションと比べると、バンドラーを介さずランタイムでコンテンツをコンパイルするため、ビルド時の画像最適化は無効になります。
</show>

### 制限事項 [#limitations]

* ビルド時の画像最適化には対応していません。
* MDX ファイル内ではインポート/エクスポートを使用できませんが、レンダリング時にコンポーネントを渡すことはできます。

## セットアップ [#setup]

パッケージをインストールします。

```package-install
@fumadocs/local-md shiki
```

> `shiki` をインストールしているのは、バンドラーで外部化する必要があるためです。

`localMd` インスタンスを作成し、Fumadocs に接続します。

```ts title="lib/source.ts"
import { dynamicLoader } from 'fumadocs-core/source';
import { localMd } from '@fumadocs/local-md';

const docs = localMd({
  dir: 'content/docs',
  // オプション
});

const docsLoader = dynamicLoader(docs.dynamicSource(), {
  baseUrl: '/docs',
});

export async function getSource() {
  return docsLoader.get();
}
```

### スキーマ [#schema]

`frontmatterSchema` と `metaSchema` を渡すと、バリデーションに使用するスキーマをカスタマイズできます。

```ts title="lib/source.ts"
import { localMd } from '@fumadocs/local-md';
import { pageSchema, metaSchema } from 'fumadocs-core/source/schema';

const docs = localMd({
  dir: 'content/docs',
  frontmatterSchema: pageSchema.extend({
    // ...
  }),
  metaSchema: metaSchema.extend({
    // ...
  }),
});
```

  ```tsx tab="app/docs/[[...slug]]/page.tsx"
  import { notFound } from 'next/navigation';
  import { DocsBody, DocsPage, DocsTitle } from 'fumadocs-ui/layouts/docs/page';
  import { getSource } from '@/lib/source';
  import { getMDXComponents } from '@/components/mdx';

  export default async function Page(props: PageProps<'/docs/[[...slug]]'>) {
    const params = await props.params;
    const source = await getSource();
    const page = source.getPage(params.slug);
    if (!page) notFound();

    const { render } = await page.data.load();
    const { body, toc } = await render(getMDXComponents());

    return (
      <DocsPage toc={toc}>
        <DocsTitle>{page.data.title}</DocsTitle>
        <DocsBody>{body}</DocsBody>
      </DocsPage>
    );
  }
  ```
</show>

  ```tsx title="app/routes/docs.tsx"
  import type { Route } from './+types/docs';
  import { useMemo } from 'react';
  import { DocsLayout } from 'fumadocs-ui/layouts/docs';
  import { DocsBody, DocsPage, DocsTitle } from 'fumadocs-ui/layouts/docs/page';
  import { useFumadocsLoader } from 'fumadocs-core/source/client';
  import { rendererFromSerialized } from '@fumadocs/local-md/client';
  import { getSource } from '@/lib/source';
  import { useMDXComponents } from '@/components/mdx';

  export async function loader({ params }: Route.LoaderArgs) {
    const source = await getSource();
    const page = source.getPage(params['*'].split('/').filter((v) => v.length > 0));
    if (!page) throw new Response('Not found', { status: 404 });

    const { serialize } = await page.data.load();
    return {
      title: page.data.title,
      // 構文木（クライアントでレンダリングされます）

    const renderer = useMemo(() => rendererFromSerialized(render), [render]);
    const { body, toc } = renderer.renderSync(useMDXComponents());

    return (
      <DocsLayout tree={pageTree}>
        <DocsPage toc={toc}>
          <DocsTitle>{title}</DocsTitle>
          <DocsBody>{body}</DocsBody>
        </DocsPage>
      </DocsLayout>
    );
  }
  ```

### インクルード [#include]

[`<include>`](/docs/mdx/include) はデフォルトで有効になっています。

```mdx title="content/docs/page.mdx"
<include>../shared/note.md</include>
```

Markdown ファイルでは、`remark-directive` を設定したうえで `::include[../shared/note.md]` ディレクティブを使用します。

```ts title="lib/source.ts"
import remarkDirective from 'remark-directive';

const docs = localMd({
  dir: 'content/docs',
  mdOptions: { remarkPlugins: [remarkDirective] },
});
```

### ホットリロード [#hot-reload]

`@fumadocs/local-md` はランタイムにファイルを読み込むため、デフォルトではファイルの変更は監視されません。

<show when={props.framework === 'next'}>
  開発中は、同梱の開発サーバーをアプリと並行して実行してください。開発サーバーは単一のプロセスでファイルを監視し、変更を WebSocket 経由でブロードキャストするため、Next.js が複数のワーカーを実行する場合でも動作します。

  ```json title="package.json"
  {
    "scripts": {
      "dev": "local-md dev -- next dev"
    }
  }
  ```

  ソースを開発サーバーに接続します。

  ```ts title="lib/source.ts"
  import { watchWithDevServer } from '@fumadocs/local-md/dev/ws';

  if (process.env.NODE_ENV === 'development') {
    void watchWithDevServer(docs);
  }
  ```

  コマンドが環境変数経由で URL を公開するため、設定は不要です。サーバーを自分で起動する場合は URL を明示的に渡してください。ポートを変更するには `-p` を使用します。

  ```ts
  void watchWithDevServer(docs, { url: 'ws://127.0.0.1:8000/_fumadocs_local_md' });
  ```

  これによりサーバー上のソースは無効化されますが、ブラウザ側では Next.js がレンダリング済みのページを保持したままです。ページも更新されるように、ルートレイアウトで `<DevClient />` をレンダリングしてください。

  ```tsx title="app/layout.tsx"
  import { DevClient } from '@fumadocs/local-md/dev/react-client';

  export function RootLayout({ children }) {
    return (
      <RootProvider>
        {/* [!code ++] */}
        <DevClient />
        {children}
      </RootProvider>
    );
  }
  ```
</show>

  ### Nitro [#nitro]

  Nitro でデプロイする場合は、Vite の設定に次の 2 つの変更を加えてください。

  ```ts title="vite.config.ts"
  import { defineConfig } from 'vite';
  import { nitro } from 'nitro/vite';

  export default defineConfig({
    plugins: [
      // Nitro は Shiki の Wasm インポートをバンドルできません。Shiki のデフォルトのエントリーはバイナリをインライン化しています
      nitro({ wasm: false }),
    ],
    resolve: {
      alias: [
        // Nitro はこの shim の `require('react')` を残すため、ランタイムで 2 つ目の React が読み込まれてしまいます
        { find: /^use-sync-external-store\/shim$/, replacement: 'react' },
      ],
    },
  });
  ```

### JavaScript エンジン [#javascript-engine]

MDX ファイル(`*.mdx`)は `new Function` で実行されるため、`eval()` が禁止されている環境(Cloudflare Workers など)では動作しません。

Markdown ファイル(`*.md`)は `eval()` を使わずに構文木からレンダリングされます。プラグインが生成した JSX は、組み込みの仮想 JavaScript エンジンで評価されます。このエンジンは `rendererOptions.executor` で差し替えられます。

<Callout type="warn">
  信頼できない MDX ファイルは `dir` に置かないでください。アプリ内で JavaScript として実行されます。
</Callout>

### 再検証を無効にする [#disable-revalidation]

`staticSource()` は、再検証を行わない一度きりのスナップショットを返します。`dynamicLoader()` ではなく `loader()` と組み合わせて使用します：

```ts title="lib/source.ts"
import { loader } from 'fumadocs-core/source';
import { localMd } from '@fumadocs/local-md';

const docs = localMd({
  dir: 'content/docs',
});

export const source = loader(await docs.staticSource(), {
  baseUrl: '/docs',
});
```
