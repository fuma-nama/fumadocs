## OpenAPI Server [#openapi-server]

Fumadocs OpenAPI のメイン設定です。

> ブラウザ環境から参照しないでください。

### `input` [#input]

読み込む OpenAPI スキーマです。

* ファイルパス
* 外部 URL
* 関数 (後述) 

読み込めるのはここに指定したスキーマのみです。それ以外の ID を `getSchema()` に渡したり、ページでプリロードしたりするとエラーがスローされます。

<Callout type="warn">
  信頼できないスキーマを `input` に渡さないでください。スキーマ内の `$ref` によって、ローカルファイルが読み取られたり、プライベートホストを含む任意の URL がフェッチされたりする可能性があります。
</Callout>

```ts tab="Basic"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  input: ['./unkey.json'],
});
```

```ts tab="Functions"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  input: {
    // [id]: ダウンロードした OpenAPI スキーマ
    my_schema: async () => {
      const res = await fetch('https://registry.scalar.com/@scalar/apis/galaxy/latest?format=json');
      return res.json();
    },
  },
});
```

## ドキュメントを一度だけ読み込む [#loading-documents-once]

ページは props でドキュメント全体を受け取るため、ページの読み込み、ナビゲーション、プリフェッチのたびにドキュメントが再送信されます。ドキュメントが大きい場合は、props に含めないようにしてください。

```ts title="lib/openapi.ts"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  // ID は URL に含まれるため、URL セーフにしてください
  input: { museum: './museum.yaml' },
  includeDocument: false, // [!code ++]
});
```

</show>

<show when={props.framework === 'next'}>
  ```tsx title="components/api-page.tsx"
  'use client';

  import { createOpenAPIPage } from 'fumadocs-openapi/ui';
  ```

  TanStack Start のルートローダーはサーバーとブラウザの両方で実行されるため、docs ルートでは `loadDocument` を使わずにドキュメントを読み込めます。server function は、ブラウザにまだドキュメントがない場合にのみ呼び出してください。

  ```tsx title="src/routes/docs/$.tsx"
  import { createServerFn } from '@tanstack/react-start';
  import type { Document } from 'fumadocs-openapi';
  import { openapi } from '@/lib/openapi';

  // ブラウザで読み込み済みのドキュメント
  const documents = new Map<string, Document>();

  const getDocument = createServerFn({ method: 'GET' })
    .validator((id: string) => id)
    .handler(async ({ data: id }) => (await openapi.getSchema(id)).bundled);

  export const Route = createFileRoute('/docs/$')({
    component: Page,
    loader: async ({ params }) => {
      const data = await serverLoader({ data: params._splat?.split('/') ?? [] });
      if (data.type === 'openapi') {
        const { document: id, payload } = data.props;
        payload.bundled = documents.get(id) ?? (await getDocument({ data: id }));
      }
      return data;
    },
  });

  function Page() {
    const page = useFumadocsLoader(Route.useLoaderData());
    // 最初のページのドキュメントも保持する
    if (page.type === 'openapi' && typeof window !== 'undefined')
      documents.set(page.props.document, page.props.payload.bundled!);
    // ...
  }
  ```
</show>

## プロキシの作成 [#creating-proxy]

プロキシサーバーは、ブラウザの CORS 制限を受けずに HTTP リクエストを送信します。API プレイグラウンドでは、次の用途でプロキシを使用します。

* CORS で自分のオリジンが許可されていない API エンドポイントへのリクエスト。
* コンフィデンシャルクライアント (クライアントシークレットを使用) の OAuth リクエストおよびデバイスフロー。

<Callout type="warn">
  プロキシは認証なしで公開されます。`Authorization` を含め、リクエストのヘッダーとボディはそのまま転送されます。[`allowedOrigins`](#allowed-origins) と `filterRequest` でアクセスを制限してください。
</Callout>

### セットアップ [#setup]

プロキシ用のルートハンドラーを作成します。

<show when={props.framework === 'next'}>

  ```ts title="app/api/proxy/route.ts"
  export const { GET, HEAD, PUT, POST, PATCH, DELETE } = openapi.createProxy();
  ```
</show>

<show when={props.framework === 'react-router'}>
  ```ts tab="app/routes/proxy.ts"

  import { openapi } from '@/lib/openapi';

  const proxy = openapi.createProxy();

  export const loader = ({ request }: Route.LoaderArgs) => proxy.handle(request);
  export const action = ({ request }: Route.ActionArgs) => proxy.handle(request);
  ```

  ```ts tab="app/routes.ts"
  import { route, type RouteConfig } from '@react-router/dev/routes';

  export default [
    // [!code ++]
    route('api/proxy', 'routes/proxy.ts'),
    // ...
  ] satisfies RouteConfig;
  ```
</show>

次に、`createOpenAPI()` でこのルートの URL を設定します。

```ts title="lib/openapi.ts"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  proxyUrl: '/api/proxy', // [!code ++]
});
```

### 許可するオリジン [#allowed-origins]

デフォルトでは、プロキシはあらゆるパブリックなオリジンを受け付けますが、プライベートネットワーク上のホスト (例: `localhost`) は拒否し、サイトの Cookie も転送しません。
プロキシの対象を制限したい場合や、プライベートな API をプロキシしたい場合は、プロキシのルートで許可するオリジンを指定してください。

```ts
openapi.createProxy({
  // 文字列または正規表現
  allowedOrigins: ['https://api.example.com', 'http://localhost:8080'],
});
```

リダイレクト先も同じルールでチェックされます。

<Callout type="warn">
  プライベートネットワークの拒否には Node.js または Deno が必要です。Bun などの他のランタイムでは、
  `allowedOrigins` を指定してください。
</Callout>

リクエストを拒否するには `filterRequest` を使用します。たとえば、読み取りのみを許可するには次のようにします。

```ts
openapi.createProxy({
  // false を返したリクエストはプロキシされずに拒否されます
  filterRequest: (request) => request.method === 'GET',
});
```

## OAuth リダイレクト [#oauth-redirect]

OAuth プロバイダーは登録済みのリダイレクト URI しか受け付けませんが、API プレイグラウンドはデフォルトで現在のページにリダイレクトします。
そこで、全ページ共通のリダイレクト URI となるルートハンドラーを作成してください。このハンドラーは、フローを開始したページへユーザーを戻します。

<show when={props.framework === 'next'}>
  ```ts title="app/api/oauth/route.ts"
  import { openapi } from '@/lib/openapi';

  export const GET = openapi.createOAuthHandler();
  ```
</show>

<show when={props.framework === 'react-router'}>
  ```ts tab="app/routes/oauth.ts"

  import { openapi } from '@/lib/openapi';

  const handler = openapi.createOAuthHandler();

  export const loader = ({ request }: Route.LoaderArgs) => handler(request);
  ```

  ```ts tab="app/routes.ts"
  import { route, type RouteConfig } from '@react-router/dev/routes';

  export default [
    // [!code ++]
    route('api/oauth', 'routes/oauth.ts'),
    // ...

  ```
</show>

  ```ts title="src/pages/api/oauth.ts"
  export const prerender = false;
  ```

このルートの URL を `createOpenAPIPage()` に渡し、完全な URL(例: `https://docs.example.com/api/oauth`)を OAuth プロバイダーに登録してください。

```tsx title="components/api-page.tsx"
export const OpenAPIPage = createOpenAPIPage({
  oauthRedirectUrl: '/api/oauth', // [!code ++]
});
```

<Callout title="Content Security Policy">
  ハンドラーは、自身のルートから配信されるスクリプトを使ってユーザーを元のページに戻します。このルートに Content Security Policy が適用される場合は、`'self'` のスクリプトを許可する必要があります。`'strict-dynamic'` を含むポリシーでは `'self'` が無視されるため、代わりにこのルートをポリシーの対象から除外してください。
</Callout>

### 静的サイト [#static-sites]

静的サイトでは、ルートはファイルとしてプリレンダリングされます。`inline: true` を渡してスクリプトをページ内に埋め込み、静的ホストがファイルを HTML として配信できるよう、パスの末尾を `.html` にしてください。

<show when={props.framework === 'next'}>

  ```ts title="app/api/oauth.html/route.ts"
  export const dynamic = 'force-static';

  export const GET = openapi.createOAuthHandler({ inline: true });
  ```
</show>
