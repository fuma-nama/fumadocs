## 設定 [#setup]

請安裝所需的套件。

```npm
npm i fumadocs-openapi shiki
```

### 產生樣式 [#generate-styles]

請加入下面這一行：

```css title="Tailwind CSS"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
/* [!code ++] */
@import 'fumadocs-openapi/css/preset.css';
```

### 設定外掛 [#configure-plugin]

建立 OpenAPI 伺服器實例及 `<OpenAPIPage />` 元件。

```ts tab="lib/openapi.ts"
import { createOpenAPI } from 'fumadocs-openapi/server';

// 注意：這是伺服器端 API
export const openapi = createOpenAPI({
  // OpenAPI schema，也可以改為提供外部 URL。
  input: ['./openapi.json'],
});
```

```tsx tab="components/api-page.tsx"
'use client';
import { createOpenAPIPage } from 'fumadocs-openapi/ui';

export const OpenAPIPage = createOpenAPIPage();
```

如需了解可用選項，請參閱 [`createOpenAPI()`](/docs/integrations/openapi/server) 與 [`createOpenAPIPage()`](/docs/integrations/openapi/api-page)。

`staticSource()` 預設會為每個 operation 產生一個頁面。如需自訂，請參閱[產生頁面](/docs/integrations/openapi/generate-files)。

**`source` 的頁面現在有 `docs` 與 `openapi` 兩種類型。** 請更新所有使用到 `source` 的地方，例如為 LLM 回傳文字的程式碼：

```ts
import { llms } from 'fumadocs-core/source';
import { source } from '@/lib/source';

export const docsLlms = llms(source, {
  renderPage: (page) => {
    // [!code ++:4]
    if (page.type === 'openapi') {
      // 例如：回傳序列化為字串的 OpenAPI schema
      return JSON.stringify(page.data.getSchema().bundled, null, 2);
    }

    // 以下為您原本的流程……
  },
});
```

<show when={props.framework === 'react-router'}>
  ```tsx title="app/routes/docs.tsx"
  import { docs, source } from '@/lib/source'; // [!code --]
  // [!code ++:3]
  import { docs } from '@/lib/collections';
  import { source } from '@/lib/source';
  import { OpenAPIPage } from '@/components/api-page';

  export async function loader({ params }: Route.LoaderArgs) {
    const slugs = params['*'].split('/').filter((v) => v.length > 0);
    const page = source.getPage(slugs);
    if (!page) throw new Response('Not found', { status: 404 });

    // [!code ++:9]
    const pageTree = await source.serializePageTree(source.getPageTree());
    if (page.type === 'openapi') {
      return {
        type: 'openapi' as const,
        title: page.data.title,
        props: page.data.getOpenAPIPageProps(),
        pageTree,
      };
    }

    return { type: 'docs' as const, path: page.path, pageTree }; // [!code highlight]
  }

  export default function Page({ loaderData }: Route.ComponentProps) {
    const data = useFumadocsLoader(loaderData);

    return (
      <DocsLayout {...baseOptions()} tree={data.pageTree}>
        {/* [!code ++:8] */}
        {data.type === 'openapi' && (
          <DocsPage full>
            <DocsTitle>{data.title}</DocsTitle>
            <DocsBody>
              <OpenAPIPage {...data.props} />
            </DocsBody>
          </DocsPage>
        )}
        {/* [!code highlight] */}
        {data.type === 'docs' && <Content path={data.path} />}
      </DocsLayout>
    );
  }
  ```

  import { type SerializedPageTree, useFumadocsLoader } from 'fumadocs-core/source/client';
  import { DocsLayout } from 'fumadocs-ui/layouts/docs';
  import { DocsBody, DocsPage, DocsTitle } from 'fumadocs-ui/layouts/docs/page';
  import { OpenAPIPage } from '@/components/api-page';
  import { Provider, type ProviderProps } from '@/components/provider';
  import { baseOptions } from '@/lib/layout.shared';
  import type { OpenAPIPageProps } from 'fumadocs-openapi/ui';

  export function OpenAPIDocs({
    tree,
    title,
    props,
    ...rest
  }: ProviderProps & { tree: SerializedPageTree; title?: string; props: OpenAPIPageProps }) {
    const data = useFumadocsLoader({ tree });

    return (
      <Provider {...rest}>
        <DocsLayout {...baseOptions()} tree={data.tree}>
          <DocsPage full>
            <DocsTitle>{title}</DocsTitle>
            <DocsBody>
              <OpenAPIPage {...props} />
            </DocsBody>
          </DocsPage>
        </DocsLayout>
      </Provider>
    );
  }

## 功能 [#features]

官方 OpenAPI 整合支援：

* 基本的 API 端點資訊
* API 互動測試區
* 傳送請求的範例程式碼 (支援多種程式語言) 
* 回應範例與 TypeScript 型別定義
* 根據 schema 產生的請求參數與 body
