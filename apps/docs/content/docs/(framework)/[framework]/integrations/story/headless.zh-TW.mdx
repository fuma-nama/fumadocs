## 概覽 [#overview]

`@fumadocs/story` 匯出 `<StoryProvider />`、`useStory()` 與 `useStoryArgs()`，提供不含 UI 的元件情境狀態：

* 所選的變體，以及其對應的預設組合
* 已渲染元件的引數，並經過防抖 (debounce) 處理，輸入時不會每按一次鍵就重新算繪元件

內建面板就是以這些 API 打造而成，您也可以改用自己的面板。

## 自訂面板 [#your-own-panel]

`defineStoryFactory()` 可接受一個 `WithControl` 元件，已渲染時會用它取代內建面板。

<show when={props.framework === 'next'}>
  ```tsx title="lib/story.tsx"
  import { defineStoryFactory } from '@fumadocs/story/next/client';
  import { StoryPanel } from '@/components/story-panel';

  export const { defineStory } = defineStoryFactory({ WithControl: StoryPanel });
  ```
</show>

<show when={props.framework !== 'next'}>
  ```tsx title="lib/story.tsx"
  import { defineStoryFactory } from '@fumadocs/story/vite/client';
  import { StoryPanel } from '@/components/story-panel';

  export const { defineStory } = defineStoryFactory({ WithControl: StoryPanel });
  ```
</show>

此元件會接收元件情境的預設組合，以及要算繪的元件。

```tsx title="components/story-panel.tsx"
'use client';
import { StoryProvider, useStory, useStoryArgs, type WithControlProps } from '@fumadocs/story';

export function StoryPanel(props: WithControlProps) {
  return (
    <StoryProvider {...props}>
      <Content />
    </StoryProvider>
  );
}

function Content() {
  const { presets, variant, setVariant, preset, Component } = useStory();
  const args = useStoryArgs();

  return (
    <div>
      <select value={variant} onChange={(e) => setVariant(e.target.value)}>
        {presets.map((item) => (
          <option key={item.variant} value={item.variant}>
            {item.variant}
          </option>
        ))}
      </select>
      <Component {...args} />
      <pre>{JSON.stringify(preset?.controls, null, 2)}</pre>
    </div>
  );
}
```

| Hook              | 說明                                                                       |
| ----------------- | ------------------------------------------------------------------------ |
| `useStory()`      | 預設組合、目前選取的 `variant` 與 `setVariant`、`Component` 以及 `frame`。              |
| `useStoryArgs()`  | 已渲染元件的引數，會隨控制項變動。                                                        |
| `useStoryFrame()` | [`frame`](/docs/integrations/story#frame) iframe 的 ref，負責將引數傳送給該 iframe。 |

控制項透過 [`@fumari/stf`](https://github.com/fuma-nama/fumadocs/tree/dev/packages/stf) 編輯，也就是 `<StoryProvider />` 所設定的表單引擎。`preset.controls` 是元件 props 的[型別樹](/docs/integrations/story#controls)。

<Callout title="從內建面板著手">
  要從頭撰寫完整的控制面板，就必須處理型別樹中的每一種節點類型。建議您安裝下方的內建面板，
  再依需求修改。
</Callout>

## 安裝 UI [#install-the-ui]

整個面板，包括其中的引數控制項：

```npm
npx @fumadocs/cli add story/controls
```
