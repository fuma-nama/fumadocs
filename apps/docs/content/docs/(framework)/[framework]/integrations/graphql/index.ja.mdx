## セットアップ [#setup]

必要なパッケージをインストールします。

```npm
npm i @fumadocs/graphql graphql
```

### スタイルの生成 [#generate-styles]

次の行を追加します。

```css title="Tailwind CSS"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
/* [!code ++] */
@import '@fumadocs/graphql/css/preset.css';
```

### プラグインの設定 [#configure-plugin]

GraphQL サーバーインスタンスと `<GraphQLPage />` コンポーネントを作成します。

```ts tab="lib/graphql.ts"
import { createGraphQL } from '@fumadocs/graphql/server';

// 注: これはサーバーサイドAPIです
export const graphql = createGraphQL({
  // GraphQLスキーマ。次の形式を指定できます:
  // SDLファイル/URL(`extend type` を含む)、SDLテキスト、
  // イントロスペクション結果、`GraphQLSchema` インスタンス。
  input: ['./schema.graphql'],
});
```

```tsx tab="components/api-page.tsx"
'use client';
import { createGraphQLPage } from '@fumadocs/graphql/ui';

export const GraphQLPage = createGraphQLPage({
  playground: {
    // オペレーションページでインタラクティブなプレイグラウンドを有効にします(省略可)
    url: 'https://api.example.com/graphql',
  },
});
```

各オプションについては、[`createGraphQL()`](/docs/integrations/graphql/server) と [`createGraphQLPage()`](/docs/integrations/graphql/api-page) を参照してください。

### ページを生成する [#generate-pages]

[`loader()`](/docs/headless/source-api/source) に `staticSource()` を渡します。ファイルを書き出さずにページを生成できます。

`staticSource()` はオペレーションごとに1ページを生成し、種類別のフォルダー (例: `queries/`) にまとめます。名前付き型のページは[オプトイン](/docs/integrations/graphql/server#includeoperations--includetypes)で生成されます。

**`source` のページは `docs` と `graphql` の2種類になりました。** `source` を使用しているすべての箇所を更新してください。

<show when={props.framework === 'react-router'}>
  ```tsx title="app/routes/docs.tsx"
  import { docs, source } from '@/lib/source'; // [!code --]
  // [!code ++:3]
  import { docs } from '@/lib/collections';
  import { source } from '@/lib/source';
  import { GraphQLPage } from '@/components/api-page';

  export async function loader({ params }: Route.LoaderArgs) {
    const slugs = params['*'].split('/').filter((v) => v.length > 0);
    const page = source.getPage(slugs);
    if (!page) throw new Response('Not found', { status: 404 });

    // [!code ++:9]
    const pageTree = await source.serializePageTree(source.getPageTree());
    if (page.type === 'graphql') {
      return {
        type: 'graphql' as const,
        title: page.data.title,
        props: page.data.getGraphQLPageProps(),
        pageTree,
      };
    }

    return { type: 'docs' as const, path: page.path, pageTree }; // [!code highlight]
  }

  export default function Page({ loaderData }: Route.ComponentProps) {
    const data = useFumadocsLoader(loaderData);

    return (
      <DocsLayout {...baseOptions()} tree={data.pageTree}>
        {/* [!code ++:8] */}
        {data.type === 'graphql' && (
          <DocsPage full>
            <DocsTitle>{data.title}</DocsTitle>
            <DocsBody>
              <GraphQLPage {...data.props} />
            </DocsBody>
          </DocsPage>
        )}
        {/* [!code highlight] */}
        {data.type === 'docs' && <Content path={data.path} />}
      </DocsLayout>
    );
  }
  ```

## 機能 [#features]

公式の GraphQL インテグレーションは、以下の機能をサポートしています。

* オペレーション(query/mutation/subscription)ごとのページ。使用している型をその場で展開して確認できます
* 引数、フィールド、非推奨情報、デフォルト値、`@oneOf` 入力オブジェクト
* スキーマで適用されているディレクティブとその定義
* リクエストとレスポンスの例(自動生成、または[独自のオペレーション](/docs/integrations/graphql/server#examples)を使用)
* cURL、JavaScript、Go、Python、Java、C#、Rust のコードサンプル
* 変数フォームを備えたプレイグラウンド。WebSocket や SSE 経由で[サブスクリプション](/docs/integrations/graphql/api-page#subscriptions)も実行できます
* LLM 向けの[ページの Markdown](/docs/integrations/graphql/server#markdown-for-llms)
* 名前付き型のページ(任意)。スキーマ全体での使用箇所も表示されます
