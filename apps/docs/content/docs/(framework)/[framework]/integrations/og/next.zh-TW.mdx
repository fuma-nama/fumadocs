## 中繼資料圖片 [#metadata-image]

您可以使用 `next/og` 動態產生中繼資料圖片。

請在載入器下方加入以下內容，並為頁面定義圖片中繼資料：

```ts tab="lib/source.ts"
// [!code ++:8]
export function getPageImageUrl(page: (typeof source)['$inferPage']) {
  const segments = [...page.slugs, 'image.png'];

  return {
    segments,
    url: '/' + [page.locale, 'og', 'docs', ...segments].filter(Boolean).join('/'),
  };
}
```

```tsx tab="app/docs/[[...slug]]/page.tsx"
import { notFound } from 'next/navigation';
import { source, getPageImageUrl } from '@/lib/source';
import type { Metadata } from 'next';

export async function generateMetadata(props: PageProps<'/docs/[[...slug]]'>): Promise<Metadata> {
  const params = await props.params;
  const page = source.getPage(params.slug);
  if (!page) notFound();

  return {
    title: page.data.title,
    description: page.data.description,
    openGraph: {
      // [!code ++]
      images: getPageImageUrl(page).url,
    },
  };
}
```

> 我們會在 slug 的結尾附加 `image.png`，以便透過 `/og/docs/my-page/image.png` 存取圖片。

最後，建立一個路由處理常式，在建置時產生圖片：

<include cwd meta="title=&#x22;app/og/docs/[...slug]/route.tsx&#x22;">
  ../../examples/next/app/og/docs/&#91;...slug&#93;/route.tsx
</include>

您可以為 Satori (`next/og` 底層使用的函式庫) 指定選項，詳情請參考 https://github.com/vercel/satori 。

### 其他預設樣式 [#other-presets]

Fumadocs CLI 也提供其他可用的樣式，例如 `mono`：

```npm
npx @fumadocs/cli@latest add og/mono
```

將原本的 `generate` 替換為您剛安裝的版本。
