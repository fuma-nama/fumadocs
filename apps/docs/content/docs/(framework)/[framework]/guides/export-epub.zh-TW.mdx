## 簡介 [#introduction]

EPUB 整合可讓您將 Fumadocs 文件匯出為 EPUB 檔案，方便讀者下載，並在電子閱讀器、平板電腦或任何支援 EPUB 的應用程式上閱讀您的文件。

它會將您的 MDX 內容轉換為 HTML、處理圖片路徑，並產生符合標準且附有目錄的 EPUB 檔案。

## 設定 [#setup]

Fumadocs CLI 可以幫您完成設定。它會建立受 `EXPORT_SECRET` 保護的匯出路由，並啟用 `includeProcessedMarkdown`：

```package-install
npx @fumadocs/cli feature epub
```

或是手動設定：

### 安裝 [#installation]

```npm
npm install fumadocs-epub
```

### 啟用處理後的 Markdown [#enable-processed-markdown]

### 建立匯出路由 [#create-export-route]

`createEpubExportAPI` 會建立路由處理常式，並以 `secret` 加以保護：若請求未帶有相符的 `Authorization: Bearer <secret>` 標頭，就會遭到拒絕；若密鑰本身未設定，路由則會回應 `503`。

<show when={props.framework === 'next'}>
  ```ts title="app/export/epub/route.ts"
  import { source } from '@/lib/source';
  import { createEpubExportAPI } from 'fumadocs-epub';

  export const revalidate = false;

  export const { GET } = createEpubExportAPI({
    source,
    title: 'My Documentation',
    author: 'My Team',
    description: 'Documentation for my project',
    cover: '/cover.png',
    secret: process.env.EXPORT_SECRET,
  });
  ```
</show>

<show when={props.framework === 'react-router'}>
  ```ts tab="app/routes/export.epub.ts"
  import type { Route } from './+types/export.epub';
  import { source } from '@/lib/source';
  import { createEpubExportAPI } from 'fumadocs-epub';

  const api = createEpubExportAPI({
    source,
    title: 'My Documentation',
    secret: process.env.EXPORT_SECRET,

  export function loader({ request }: Route.LoaderArgs) {
  ```

</show>

## 選項 [#options]

`exportEpub` 與 `createEpubExportAPI` 皆接受以下選項：

| 選項             | 型別                                            | 說明                                                                      |
| -------------- | --------------------------------------------- | ----------------------------------------------------------------------- |
| `source`       | `LoaderOutput \| () => Promise<LoaderOutput>` | **必填。** 來自 `loader()` 的來源，或可解析出來源的函式                                    |
| `title`        | `string`                                      | **必填。** 書名                                                              |
| `author`       | `string \| string[]`                          | 作者名稱 (可多位) 。預設：`'anonymous'`                                            |
| `description`  | `string`                                      | 書籍說明                                                                    |
| `language`     | `string`                                      | 語言代碼 (例如 `'en'`) 。預設：`'en'`                                             |
| `publisher`    | `string`                                      | 出版者名稱。預設：`'anonymous'`                                                  |
| `cover`        | `string`                                      | 封面圖片。支援 `file://`、`http(s)://`、`/public/...` 或相對路徑                      |
| `outputPath`   | `string`                                      | 若有設定，除了回傳緩衝區外，也會將 EPUB 寫入檔案                                             |
| `includePages` | `(page) => boolean`                           | 篩選：僅納入此函式回傳 `true` 的頁面                                                  |
| `excludePages` | `(page) => boolean`                           | 篩選：排除此函式回傳 `true` 的頁面                                                   |
| `getMarkdown`  | `(page) => string \| undefined`               | 取得頁面的 Markdown，回傳 `undefined` 時略過該頁。預設：`page.data.getText('processed')` |
| `css`          | `string`                                      | EPUB 的自訂 CSS。省略時使用 `defaultEpubStyles`                                  |
| `publicDir`    | `string`                                      | 用於解析 `/public/...` 圖片路徑的 public 目錄。預設：`./public`                        |

`createEpubExportAPI` 另外提供兩個選項：`secret` (必填，用於保護路由) 與 `filename` (下載的檔案名稱，預設為 `docs.epub`) 。

### 自訂 CSS [#custom-css]

您可以覆寫預設的 EPUB 樣式：

```ts
import { exportEpub, defaultEpubStyles } from 'fumadocs-epub';

const buffer = await exportEpub({
  source,
  title: 'My Docs',
  author: 'Me',
  css: `${defaultEpubStyles}
/* 自訂覆寫 */
body { font-size: 1.1em; }
`,
});
```

### 篩選頁面 [#filtering-pages]

使用 `includePages` 與 `excludePages` 控制要匯出哪些文件：

```ts
const buffer = await exportEpub({
  source,
  title: 'My Docs',
  author: 'Me',
  // 僅納入 /docs/getting-started 底下的文件
  includePages: (page) => page.path.startsWith('getting-started'),
  // 排除特定路徑
  excludePages: (page) => page.path === 'changelog',
});
```

### 圖片解析 [#image-resolution]

MDX 中的圖片會自動解析：

* **相對路徑** (例如 `./image.png`) ：以頁面檔案所在位置為基準解析
* **公開路徑** (例如 `/og.png`) ：從 `public` 目錄解析
* **遠端 URL** (例如 `https://...`) ：直接原樣嵌入
