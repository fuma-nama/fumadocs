## Getting Started

Before continuing, make sure to configure Astro 7 and Tailwind CSS 4.

Docs are MDX files of Astro content collections, the integration adds the Markdown features of Fumadocs to them. Fumadocs UI renders in React islands.

### Installation

```npm
npm i fumadocs-core fumadocs-ui @fumadocs/astro @astrojs/react @astrojs/mdx react react-dom
```

### Configuration

Add the Fumadocs integration, it adds the React and MDX integrations for you:

## Rendering

The MDX content of each page renders as one React island (`client:load`). Its components share a React tree and hydrate like on other frameworks, including JSX props like `icon={<Icon />}`.

Astro renders the parts React can't, inside the island:

- Highlighted code.
- Images, with the image pipeline of Astro.
- Components imported in the MDX file, including Astro components. Framework components keep the rules of Astro, add `client:load` to hydrate them.
- `{expressions}`.

<Callout title="Good to know">

- Props of the components in your `components` module are serialized into the island, they must be JSON-serializable (no functions).
- The island is a React tree of its own, providers of your layout don't reach it. `wrapper` receives the props of `<Content />`, use it to add providers, like for [Internationalization](/docs/internationalization/astro).
- The theme state isn't shared either, style light/dark mode with CSS (e.g. `dark:` variants) rather than `useTheme()`.

</Callout>

## Options

```js title="astro.config.mjs"
fumadocs({
  // module whose default export is the MDX components
  components: './src/components/mdx.tsx',
  // content directories, relative to the project root
  collections: {
    docs: { dir: 'content/docs' },
  },
  // enable `getText('processed')` on pages
  includeProcessedMarkdown: false,
});
```

Options other than `components` are optional, the values above are their defaults. The integration adds `@astrojs/react` and `@astrojs/mdx` with their default options, add them to `integrations` yourself to configure them.

### Collections

Fumadocs only processes the MDX files of its collections, other Markdown of your project is left to Astro.

Add a collection for each content directory, like a blog with its own MDX components:

```js title="astro.config.mjs"
fumadocs({
  components: './src/components/mdx.tsx',
  collections: {
    docs: { dir: 'content/docs' },
    // [!code ++]
    blog: { dir: 'content/blog', components: './src/components/blog-mdx.tsx' },
  },
});
```

Load it by name, `pageLoader()` and `metaLoader()` load `docs` by default:

```ts title="src/content.config.ts"
export const collections = {
  docs: defineCollection({ loader: pageLoader(), schema: pageSchema }),
  meta: defineCollection({ loader: metaLoader(), schema: metaSchema }),
  // [!code ++]
  blog: defineCollection({ loader: pageLoader('blog'), schema: pageSchema }),
};
```

And create a source from it, meta files are optional:

```ts title="src/lib/source.ts"
export const blog = loader({
  source: toFumadocsSource(await getCollection('blog')),
  baseUrl: '/blog',
});
```

### Plugins

Add Sätteri plugins with `mdastPlugins` and `hastPlugins`, as an array or a function receiving the default plugins. For example, to render `mermaid` code blocks with the [`Mermaid` component](/docs/markdown/mermaid) of your MDX components:

```npm
npm i @fumadocs/satteri
```

```js title="astro.config.mjs"
import { remarkMdxMermaid } from '@fumadocs/satteri/remark-mdx-mermaid';

fumadocs({
  mdastPlugins: [remarkMdxMermaid()],
});
```

They only run on the collections of Fumadocs, while plugins of the `satteri()` processor of Astro apply to every Markdown file.

The built-in plugins take the same options as [Fumadocs MDX](/docs/mdx/mdx#customize-built-in-plugins): `remarkHeadingOptions`, `remarkCodeTabOptions`, `remarkNpmOptions`, `remarkStructureOptions`, `rehypeCodeOptions` and `rehypeKatexOptions`.

Fumadocs highlights the code blocks of its collections, configure it with `rehypeCodeOptions`. The `markdown.shikiConfig` of Astro only applies to other Markdown.

```js title="astro.config.mjs"
fumadocs({
  rehypeCodeOptions: {
    themes: { light: 'catppuccin-latte', dark: 'catppuccin-mocha' },
  },
});
```

## Page Data

Pages of `toFumadocsSource()` have:

```ts
// the MDX content, table of contents and structured data (for search)
const { Content, toc, structuredData } = await page.data.render();

// structured data only
await page.data.structuredData();

// the source file, or the Markdown processed by Fumadocs (requires `includeProcessedMarkdown`)
await page.data.getText('raw');
await page.data.getText('processed');

// the entry of Astro content collections
page.data.entry;
```
