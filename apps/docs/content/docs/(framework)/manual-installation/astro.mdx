## Getting Started

Before continuing, make sure to configure:

- Node.js 22.23.4 or later (required by Astro).
- Tailwind CSS 4.

Astro uses its own content collections instead of Fumadocs MDX. `@fumadocs/astro` compiles collections with Fumadocs and renders MDX as React islands.

### Installation

```npm
npm i fumadocs-core fumadocs-ui @fumadocs/astro @astrojs/react react react-dom @types/mdx
```

### Styles

Add the following to your Tailwind CSS file:

```css title="src/styles/global.css"
@import 'tailwindcss';
/* [!code ++:2] */
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
```

### Create Pages

Add the Fumadocs integration to your Astro config:

```js title="astro.config.mjs"
import { defineConfig } from 'astro/config';
import tailwindcss from '@tailwindcss/vite';
import fumadocs from '@fumadocs/astro';

export default defineConfig({
  integrations: [fumadocs({ components: './src/components/mdx.tsx' })],
  vite: {
    plugins: [tailwindcss()],
  },
});
```
