## OpenAPI Server

The main config for Fumadocs OpenAPI.

> It should not be referenced in browser environments.

### `input`

The OpenAPI schemas to read from.

- File Paths
- External URLs
- Functions (see below)

Only schemas listed here can be loaded, other IDs passed to `getSchema()` or preloaded by pages throw an error.

<Callout type="warn">

Do not pass untrusted schemas to `input`, their `$ref`s can read local files and fetch URLs, private hosts included.

</Callout>

```ts tab="Basic"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  input: ['./unkey.json'],
});
```

```ts tab="Functions"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  input: {
    // [id]: downloaded OpenAPI Schema
    my_schema: async () => {
      const res = await fetch('https://registry.scalar.com/@scalar/apis/galaxy/latest?format=json');
      return res.json();
    },
  },
});
```

## Loading Documents Once

Pages receive the whole document in their props, every page load, navigation and prefetch sends it again. For large documents, leave it out:

```ts title="lib/openapi.ts"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  // IDs end up in URLs, keep them URL-safe
  input: { museum: './museum.yaml' },
  includeDocument: false, // [!code ++]
});
```

Then load each document once per browser session:

'use client';
import { preload } from 'react-dom';
import { createOpenAPIPage } from 'fumadocs-openapi/ui';

  async loadDocument(id) {

  return Object.keys(await openapi.getSchemas()).map((id) => ({ id }));

<Tab value="Tanstack Start">

Route loaders run on both sides, call a server function only when the browser doesn't have the document yet:

```tsx title="src/routes/docs/$.tsx"
import { createServerFn } from '@tanstack/react-start';
import type { Document } from 'fumadocs-openapi';
import { openapi } from '@/lib/openapi';

// documents the browser has loaded
const documents = new Map<string, Document>();

const getDocument = createServerFn({ method: 'GET' })
  .validator((id: string) => id)
  .handler(async ({ data: id }) => (await openapi.getSchema(id)).bundled);

export const Route = createFileRoute('/docs/$')({
  component: Page,
  loader: async ({ params }) => {
    const data = await serverLoader({ data: params._splat?.split('/') ?? [] });
    if (data.type === 'openapi') {
      const { document: id, payload } = data.props;
      payload.bundled = documents.get(id) ?? (await getDocument({ data: id }));
    }
    return data;
  },
});

function Page() {
  const page = useFumadocsLoader(Route.useLoaderData());
  // the document of the first page too
  if (page.type === 'openapi' && typeof window !== 'undefined')
    documents.set(page.props.document, page.props.payload.bundled!);
  // ...
}
```

With generated MDX files, put documents in `preloaded.docs` instead.

## Creating Proxy

A proxy server is useful for executing HTTP (`fetch`) requests, as it doesn't have CORS constraints like on the browser.

We use it for:

- Executing HTTP requests on the OpenAPI playground, when the target API endpoints do not have CORS configured correctly.
- OAuth requests of confidential clients (with a client secret) and device flows.

<Callout type="warn">

The proxy is public without authentication, it forwards the headers and body of requests, including `Authorization`. Restrict it with [`allowedOrigins`](#allowed-origins) and `filterRequest`.

</Callout>

### Setup

Create a route handler for proxy server.

```ts tab="Next.js" title="app/api/proxy/route.ts"
import { openapi } from '@/lib/openapi';

export const { GET, HEAD, PUT, POST, PATCH, DELETE } = openapi.createProxy();
```

```ts tab="Tanstack Start" title="app/routes/api/proxy.ts"
import { openapi } from '@/lib/openapi';
import { createFileRoute } from '@tanstack/react-router';

const proxy = openapi.createProxy();

export const Route = createFileRoute('/api/proxy')({
  server: {
    handlers: {
      // Handles all methods by default, or specify individual methods (GET, POST, etc.)
      ANY: async ({ request }) => {
        return proxy.handle(request);
      },
    },
  },
});
```

```ts tab="Waku" title="src/pages/_api/api/proxy.ts"
import { openapi } from '@/lib/openapi';

export const { GET, HEAD, PUT, POST, PATCH, DELETE } = openapi.createProxy();
```

```ts tab="Astro" title="src/pages/api/proxy.ts"
import type { APIRoute } from 'astro';
import { openapi } from '@/lib/openapi';

// rendered on demand, it requires an adapter
export const prerender = false;

const proxy = openapi.createProxy();

export const ALL: APIRoute = ({ request }) => proxy.handle(request);
```

And set the proxy URL in `createOpenAPI`.

```ts title="lib/openapi.ts"
import { createOpenAPI } from 'fumadocs-openapi/server';

export const openapi = createOpenAPI({
  proxyUrl: '/api/proxy', // [!code ++]
});
```

### Allowed Origins

By default, the proxy accepts any public origin, refuses hosts on private networks (e.g. `localhost`), and doesn't forward your site's cookies.
List the origins to restrict it, or to proxy private APIs:

```ts
openapi.createProxy({
  // strings or regular expressions
  allowedOrigins: ['https://api.example.com', 'http://localhost:8080'],
});
```

Redirects are checked by the same rules.

<Callout type="warn">
  Refusing private networks requires Node.js or Deno, specify `allowedOrigins` on other runtimes
  (e.g. Bun).
</Callout>

Use `filterRequest` to refuse requests, for example to only allow reads:

```ts
openapi.createProxy({
  // proxied requests that return false are refused
  filterRequest: (request) => request.method === 'GET',
});
```

## OAuth Redirect

OAuth providers only accept registered redirect URIs, but the API playground redirects to the current page by default.
Create a route handler as the redirect URI of every page, it sends users back to the page that started the flow.

```ts tab="Next.js" title="app/api/oauth/route.ts"
import { openapi } from '@/lib/openapi';

export const GET = openapi.createOAuthHandler();
```

```ts tab="Tanstack Start" title="app/routes/api/oauth.ts"
import { openapi } from '@/lib/openapi';
import { createFileRoute } from '@tanstack/react-router';

const handler = openapi.createOAuthHandler();

export const Route = createFileRoute('/api/oauth')({
  server: {
    handlers: {
      GET: async ({ request }) => handler(request),
    },
  },
});
```

```ts tab="Waku" title="src/pages/_api/api/oauth.ts"
import { openapi } from '@/lib/openapi';

export const GET = openapi.createOAuthHandler();
```

```ts tab="Astro" title="src/pages/api/oauth.ts"
import type { APIRoute } from 'astro';
import { openapi } from '@/lib/openapi';

// rendered on demand, it requires an adapter
export const prerender = false;

const handler = openapi.createOAuthHandler();

export const GET: APIRoute = ({ request }) => handler(request);
```

Pass its URL to `createOpenAPIPage()`, and register the full URL (e.g. `https://docs.example.com/api/oauth`) on your OAuth provider.

```tsx title="components/api-page.tsx"
export const OpenAPIPage = createOpenAPIPage({
  oauthRedirectUrl: '/api/oauth', // [!code ++]
});
```
