## Overview

Everything outside `@fumadocs/graphql/ui` is headless.

| Path                           | Module                                                               |
| ------------------------------ | -------------------------------------------------------------------- |
| `@fumadocs/graphql`            | the page: the schema built from SDL, cross-links and your components |
| `@fumadocs/graphql/operation`  | an operation: its field, title, directives and examples              |
| `@fumadocs/graphql/type-docs`  | a named type: its kind, directives, relations and usages             |
| `@fumadocs/graphql/playground` | sending operations and subscriptions, the stored state of playground |

## Page

`createGraphQLRenderer()` takes your components and returns `<GraphQLPage />`, which accepts the props of generated pages.

```tsx title="components/api-page.tsx"
'use client';
import { type CodeBlockProps, createGraphQLRenderer } from '@fumadocs/graphql';
import { Operation } from '@/components/my-operation';
import { TypeDocs } from '@/components/my-type';

export const GraphQLPage = createGraphQLRenderer({
  components: {
    Operation,
    TypeDocs,
    SchemaUI: ({ client, root }) => <pre>{`${client.name}: ${root.type}`}</pre>,
    CodeBlock({ lang, code }: CodeBlockProps) {
      return (
        <pre>
          <code className={`language-${lang}`}>{code}</code>
        </pre>
      );
    },
  },
});
```

| Component   | Renders                                                 |
| ----------- | ------------------------------------------------------- |
| `Operation` | each operation of the page, see [Operation](#operation) |
| `TypeDocs`  | each named type of the page, see [Type](#type)          |
| `SchemaUI`  | a type, argument or field in detail                     |
| `Layout`    | optional, wraps the rendered items                      |

Pass `typeLinks` and `operationLinks` to override the [cross-links](/docs/integrations/graphql/api-page#cross-linking) of pre-generated pages.

### Hooks

Components under the page read its state.

| Hook                           | Returns                                                            |
| ------------------------------ | ------------------------------------------------------------------ |
| `useGraphQL()`                 | the built `schema`, its `sdl`, the page links and examples         |
| `useComponents()`              | the components passed to the page                                  |
| `useTypeLink(name)`            | the page URL of a named type, `undefined` when unlinked            |
| `useOperationLink(kind, name)` | the page URL of an operation                                       |
| `useRenderContext()`           | the render options of the page, like `playground` and `codeUsages` |

To render operations yourself, mount `<GraphQLProvider sdl={sdl} shiki={shiki} components={...} />` in place of `createGraphQLRenderer()`.

## Operation

`<OperationProvider />` derives the details of an operation.

```tsx title="components/my-operation.tsx"
'use client';
import { useComponents } from '@fumadocs/graphql';
import {
  OperationProvider,
  type PageOperationProps,
  useOperation,
} from '@fumadocs/graphql/operation';

export function Operation({ kind, name }: PageOperationProps) {
  return (
    <OperationProvider kind={kind} name={name}>
      <Content />
    </OperationProvider>
  );
}

function Content() {
  const { title, field, examples, selected, select } = useOperation();
  const { CodeBlock, SchemaUI } = useComponents();
  const example = examples.at(selected);

  return (
    <>
      <h2>{title}</h2>
      {field.args.map((arg) => (
        <SchemaUI
          key={arg.name}
          client={{ name: arg.name, rootId: arg.name }}
          root={{ type: arg.type }}
        />
      ))}
      {examples.map((item, i) => (
        <button key={i} onClick={() => select(i)}>
          {item.name ?? 'Example'}
        </button>
      ))}
      {example && <CodeBlock lang="graphql" code={example.query} />}
    </>
  );
}
```

`examples` are the ones from the [`examples` option](/docs/integrations/graphql/server#examples), or a generated one. `selected` is shared by everything under the provider, like the example card and the playground.

## Type

`<TypeProvider />` derives the details of a named type.

```tsx title="components/my-type.tsx"
'use client';
import { useComponents } from '@fumadocs/graphql';
import { type PageTypeProps, TypeProvider, useNamedType } from '@fumadocs/graphql/type-docs';

export function TypeDocs({ name }: PageTypeProps) {
  return (
    <TypeProvider name={name}>
      <Content />
    </TypeProvider>
  );
}

function Content() {
  const { name, kind, type, relations } = useNamedType();
  const { SchemaUI } = useComponents();

  return (
    <>
      <h2>
        {name} ({kind})
      </h2>
      {relations.usages.returnedBy.map((op) => (
        <span key={`${op.kind}:${op.name}`}>{op.name}</span>
      ))}
      <SchemaUI client={{ name, rootId: name, as: 'body' }} root={{ type }} />
    </>
  );
}
```

`relations` connects the type to the rest of schema:

| Relation        | Is                                          |
| --------------- | ------------------------------------------- |
| `implements`    | the interfaces it implements                |
| `unions`        | the unions including it, for objects        |
| `implementedBy` | the objects implementing it, for interfaces |
| `possibleTypes` | the members of unions                       |
| `usages`        | where it appears across the schema          |

## Playground

`@fumadocs/graphql/playground` is the logic of the playground, without UI.

| Export                                        | Does                                                                  |
| --------------------------------------------- | --------------------------------------------------------------------- |
| `executeGraphQL(request)`                     | sends a query or mutation over HTTP POST, the default `fetcher`       |
| `subscribeGraphQL(request, handlers)`         | starts a subscription, returns a function to stop it                  |
| `getSubscriptionUrl(url)`                     | the default subscription endpoint: `url` with a `ws(s)://` scheme     |
| `inputTypeToJsonSchema(type)`                 | the JSON Schema of an input type, for forms of variables              |
| `syncOperationVariables(query, field, isSet)` | declares the variables of required and set optional arguments         |
| `readStored()`, `writeStored(state)`          | the endpoint and headers in local storage, headers by endpoint origin |

`subscribeGraphQL()` picks the protocol by the URL scheme, like [`subscriptionUrl`](/docs/integrations/graphql/api-page#subscriptions).

```ts
import { getSubscriptionUrl, subscribeGraphQL } from '@fumadocs/graphql/playground';

const stop = subscribeGraphQL(
  {
    url: getSubscriptionUrl('/api/graphql'),
    query: 'subscription { orderUpdated(id: "1") { status } }',
    headers: {},
  },
  {
    onNext: (result) => console.log(result),
    onError: (message) => console.error(message),
    onComplete: () => console.log('completed'),
  },
);

// no handler is called after it
stop();
```
