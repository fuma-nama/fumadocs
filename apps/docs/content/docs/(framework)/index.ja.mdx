Fumadocs <span className="text-fd-muted-foreground text-sm">(Foo-ma docs)</span> は、高速かつ柔軟で、お使いの React フレームワークにシームレスに組み込めるよう設計された**ドキュメントフレームワーク**です。
複数のレイヤーで構成されています。

<Cards>
  <Card icon={<CpuIcon className="text-purple-300" />} title="Fumadocs Core" href="/docs/headless">
    ドキュメント検索、コンテンツソースのアダプター、Markdown 拡張機能など、ロジックの大部分を担います。
  </Card>

  <Card icon={<PanelsTopLeftIcon className="text-blue-300" />} title="Fumadocs UI" href="/docs/ui">
    Fumadocs のデフォルトテーマです。ドキュメントサイト向けの美しいデザインと、インタラクティブなコンポーネントを提供します。
  </Card>

  <Card icon={<DatabaseIcon />} title="コンテンツソース">
    コンテンツの取得元です。CMS のほか、[Fumadocs MDX](/docs/mdx) (公式のコンテンツソース) のようなローカルデータレイヤーも利用できます。
  </Card>

  <Card icon={<TerminalIcon />} title="Fumadocs CLI" href="/docs/cli">
    UI コンポーネントのインストールや各種作業の自動化を行うコマンドラインツールです。レイアウトのカスタマイズに便利です。
  </Card>
</Cards>

## フレームワークの選択 [#choosing-a-framework]

ガイドはフレームワークごとに用意されています。アプリで使用しているフレームワークを選ぶか、新規プロジェクトの場合は Next.js を選んでください。

<Cards>
  <Card icon={<FrameworkLogo framework="next" />} title="Next.js（推奨）" href="/docs/next">
    強力で成熟したフレームワークで、新規プロジェクトの標準的な選択肢です。
  </Card>

  <Card icon={<FrameworkLogo framework="react-router" />} title="React Router" href="/docs/react-router">
    React Router アプリ向けです。SPA モードを使うと、サイトを CDN 上で静的にホスティングできます。
  </Card>

  <Card icon={<FrameworkLogo framework="tanstack-start" />} title="TanStack Start" href="/docs/tanstack-start">
    TanStack Start アプリ向けです。SPA モードを使うと、サイトを CDN 上で静的にホスティングできます。
  </Card>

  <Card icon={<FrameworkLogo framework="waku" />} title="Waku" href="/docs/waku">
    Vite ベースでサーバーコンポーネントに対応した、高速かつシンプルな React フレームワークです。
  </Card>

  <Card icon={<FrameworkLogo framework="astro" />} title="Astro" href="/docs/astro">
    Astro サイト向けです。コンテンツコレクションを利用でき、MDX は React アイランドとしてレンダリングされます。
  </Card>
</Cards>

<Callout title="よりシンプルな DX で Fumadocs を試す">
  [Fumapress](https://press.fumadocs.dev) は、Fumadocs をベースに、より多くの機能をまとめて管理するサイトジェネレーターです。

  * 自動ルーティング、`llms.txt`、MCP などの基本機能を備えています。
  * Vite ([Waku](https://waku.gg)) をベースにしています。

  独自の React フレームワークの使用が前提となりますが、その分より優れた DX を提供します。
</Callout>
