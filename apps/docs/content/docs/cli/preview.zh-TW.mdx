## 簡介 [#introduction]

`fumadocs-preview` 可讓您使用 Fumadocs 檢視 Markdown 檔案，很適合用來閱讀 skills 檔案與筆記。

請在您的專案目錄下執行此指令。

```npm
npx fumadocs-preview dir/to/content
```

### 設定 [#configurations]

如需其他設定，您可以在本機安裝：

```npm
npm install fumadocs-preview -D
```

接著初始化設定檔：

```npm
npx fumadocs-preview init
```
