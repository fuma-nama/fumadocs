## はじめに [#introduction]

`fumadocs-preview` を使うと、Markdown ファイルを Fumadocs で表示できます。スキルファイルやメモを読むのに便利です。

プロジェクトのディレクトリでコマンドを実行してください。

```npm
npx fumadocs-preview dir/to/content
```

### 設定 [#configurations]

その他の設定を行う場合は、ローカルにインストールできます。

```npm
npm install fumadocs-preview -D
```

次に、設定ファイルを初期化します。

```npm
npx fumadocs-preview init
```
