---
title: ストアの例
description: ストアを題材にした GraphQL スキーマのサンプルです。
---

[Fumadocs GraphQL](/docs/integrations/graphql) でドキュメント化したストアのスキーマです。プレイグラウンドからのリクエストはモックのエンドポイントに送信されます。

* [Customer](/docs/graphql/queries/customer) では、名前付きのサンプルから選択できます。
* [Order Updated](/docs/graphql/subscriptions/orderUpdated) では、プレイグラウンドでライブイベントをストリーミングで受信できます。
