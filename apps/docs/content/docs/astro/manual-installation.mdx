## Prerequisite

Before continuing, make sure you have configured:

- Astro 7.
- [Tailwind CSS 4](https://docs.astro.build/en/guides/styling/#tailwind).

## Getting Started

```npm
npm i fumadocs-core fumadocs-ui @fumadocs/astro @astrojs/react react react-dom
```

### Integration

Add the Fumadocs integration, it adds the Markdown features of Fumadocs to the Sätteri processor of Astro, and the React and MDX integrations:

<include cwd meta='title="astro.config.mjs"'>
  ../../examples/astro-min/astro.config.mjs
</include>

### Styles

Add the following to your Tailwind CSS file:

```css title="src/styles/global.css"
@import 'tailwindcss';
/* [!code ++:2] */
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
```

The pages of Fumadocs load `src/styles/global.css`, you don't have to import it.

### Content Collections

Define the collections of your docs pages and their [meta files](/docs/page-conventions):

<include cwd meta='title="src/content.config.ts"'>
  ../../examples/astro-min/src/content.config.ts
</include>

### Source

Create the source of your pages with the [Loader API](/docs/headless/source-api):

<include cwd meta='title="src/lib/source.ts"'>
  ../../examples/astro-min/src/lib/source.ts
</include>

### Config

Create the config of Fumadocs:

<include cwd meta='title="src/fumadocs.config.ts"'>
  ../../examples/astro-min/src/fumadocs.config.ts
</include>

From this file, the integration creates the routes of docs pages, search, LLMs and the 404 page.

### Done

You can start writing documents at `content/docs`:

```mdx title="content/docs/index.mdx"
---
title: Hello World
---

I love Fumadocs
```

Start the dev server, and open `/docs`.
