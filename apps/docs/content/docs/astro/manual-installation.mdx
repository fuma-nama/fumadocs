## Prerequisite

Before continuing, make sure you have configured:

- Node.js 22.23.4 or later.
- Astro 7.
- [Tailwind CSS 4](https://docs.astro.build/en/guides/styling/#tailwind).

## Getting Started

```npm
npm i fumadocs-core fumadocs-ui @fumadocs/astro @astrojs/react react react-dom
```

```npm
npm i -D @types/react @types/react-dom @types/mdx
```

### Integration

Add the Fumadocs integration, it adds the Markdown features of Fumadocs to the Sätteri processor of Astro, and the React and MDX integrations:

<include cwd meta='title="astro.config.mjs"'>
  ../../examples/astro-min/astro.config.mjs
</include>

The integration runs on Sätteri, the default Markdown processor of Astro, and throws when `markdown.processor` is another processor.

### Styles

Add the following to your Tailwind CSS file:

```css title="src/styles/global.css"
@import 'tailwindcss';
/* [!code ++:2] */
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
```

The pages of Fumadocs load `src/styles/global.css`, you don't have to import it.

### Source Files

Create the [collections](/docs/page-conventions), the [source](/docs/headless/source-api) and the Fumadocs config:

<include cwd meta='tab="src/content.config.ts"'>
  ../../examples/astro-min/src/content.config.ts
</include>

<include cwd meta='tab="src/lib/source.ts"'>
  ../../examples/astro-min/src/lib/source.ts
</include>

<include cwd meta='tab="src/fumadocs.config.ts"'>
  ../../examples/astro-min/src/fumadocs.config.ts
</include>

From `src/fumadocs.config.ts`, the integration creates the routes of docs pages, search, LLMs and the 404 page.

### Layout Options

Create a `layout` module for the navbar title and links, see [Layout Options](/docs/astro/layouts#layout-options).

### Home Page

Only `/docs` is generated, create a home page for `/` with [`HomeLayout.astro`](/docs/astro/layouts#your-own-pages).

### Done

You can start writing documents at `content/docs`:

```mdx title="content/docs/index.mdx"
---
title: Hello World
---

I love Fumadocs
```

Start the dev server, and open `/docs`.
