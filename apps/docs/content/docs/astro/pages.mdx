## Home Layout

Pages outside your docs are Astro routes in `src/pages`. Render the [Home Layout](/docs/ui/layouts/home-layout) with `HomeLayout.astro`, it has the navbar, styles and providers of Fumadocs:

```astro title="src/pages/about.astro"
---
import HomeLayout from '@fumadocs/astro/components/HomeLayout.astro';
---

<HomeLayout title="About" description="About my project.">
  <main class="flex flex-col flex-1 items-center justify-center">
    <h1 class="text-xl font-bold">About</h1>
  </main>
</HomeLayout>
```

The content is a child of a React island, rendered on the server only. Add `client:load` to your own framework components to hydrate them.

| Prop          | Description                                                         |
| ------------- | ------------------------------------------------------------------- |
| `title`       | Page title, followed by the site title.                             |
| `description` | Page description.                                                   |
| `lang`        | Language of the page, for [i18n](/docs/astro/internationalization). |
| `notFound`    | Render the not found page of Fumadocs UI instead of the content.    |

Add tags to `<head>` with the `head` slot:

```astro
<HomeLayout title="About">
  <meta slot="head" name="robots" content="noindex" />
</HomeLayout>
```

## Using the Source

Import your source to read pages, like a list of all pages:

```astro title="src/pages/all.astro"
---
import HomeLayout from '@fumadocs/astro/components/HomeLayout.astro';
import { source } from '@/lib/source';
---

<HomeLayout title="All Pages">
  <ul>
    {
      source.getPages().map((page) => (
        <li>
          <a href={page.url}>{page.data.title}</a>
        </li>
      ))
    }
  </ul>
</HomeLayout>
```

See [Loader API](/docs/headless/source-api) for its methods.

## Replacing a Docs Page

Your routes take priority over the docs routes. To render `/docs/test` without the docs layout, remove `content/docs/test.mdx` and create `src/pages/docs/test.astro`.

## Not Found Page

The integration adds a 404 page, unless your project has `src/pages/404.astro` (or `.md`, `.mdx`, `.html`). Your own one can render the default UI:

```astro title="src/pages/404.astro"
---
import HomeLayout from '@fumadocs/astro/components/HomeLayout.astro';
---

<HomeLayout title="Not Found" notFound />
```

## Routes Rendered on Demand

The routes of Fumadocs are prerendered, routes rendered on demand aren't supported yet. Your own routes can be, with `output: 'server'` and an [adapter](https://docs.astro.build/en/guides/on-demand-rendering).
