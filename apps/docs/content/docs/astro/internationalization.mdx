## Writing Pages

Add the language to the file name of a translation, see [i18n Routing](/docs/page-conventions#i18n-routing):

<Files>
  <Folder name="content/docs" defaultOpen>
    <File name="index.mdx" />
    <File name="index.cn.mdx" />
    <File name="meta.json" />
    <File name="meta.cn.json" />
  </Folder>
</Files>

Docs pages are created for every language, like `/docs` and `/cn/docs` above. The search dialog searches the current language.

### Links

For links that include the language, add `DynamicLink` to your MDX components:

<include cwd meta='title="src/components/mdx.tsx"'>
  ../../examples/astro-i18n/src/components/mdx.tsx
</include>

```mdx
<DynamicLink href="/[lang]/docs/setup">Setup</DynamicLink>
```

## Layout Options

`baseOptions()` receives the language, the navbar title links to the home page of the language by default:

```tsx title="src/lib/layout.shared.tsx"
import type { BaseLayoutProps } from 'fumadocs-ui/layouts/shared';

export function baseOptions(locale?: string): BaseLayoutProps {
  return {
    nav: { title: locale === 'cn' ? '文檔' : 'Docs' },
  };
}
```
