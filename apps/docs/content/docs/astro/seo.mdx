## Sitemap

Use [`@astrojs/sitemap`](https://docs.astro.build/en/guides/integrations-guide/sitemap) to list every page of your site, including docs pages and custom pages.

```npm
npx astro add sitemap
```

It requires [`site`](https://docs.astro.build/en/reference/configuration-reference/#site). Pass `serializeSitemap` as its `serialize` option:

```js title="astro.config.mjs"
import { defineConfig } from 'astro/config';
import fumadocs, { serializeSitemap } from '@fumadocs/astro'; // [!code ++]
import sitemap from '@astrojs/sitemap';

export default defineConfig({
  site: 'https://example.com', // [!code ++]
  integrations: [fumadocs(), sitemap({ serialize: serializeSitemap })], // [!code ++]
});
```

It reads the `<head>` of each built page:

- `lastmod` from `<meta property="article:modified_time">`, which docs pages with a last modified date have, like from the [Git plugin](/docs/astro/git).
- The `hreflang` links of docs pages with [internationalization](/docs/astro/internationalization).
- Pages with `noindex` are left out, like the pages shown in the fallback language.

Custom pages can render the same tags in `HomeLayout`'s `head` slot. To add `hreflang` links to them, pass the languages to the `i18n` option:

```js title="astro.config.mjs"
sitemap({
  serialize: serializeSitemap,
  i18n: {
    defaultLocale: 'en',
    // language -> `hreflang`
    locales: { en: 'en', cn: 'zh-CN' },
  },
});
```

To change the items further, call it in your own `serialize`:

```js title="astro.config.mjs"
sitemap({
  async serialize(item) {
    const result = await serializeSitemap(item);
    if (result?.url.includes('/docs/')) result.priority = 0.8;
    return result;
  },
});
```

## robots.txt

Put it in `public/`, with the sitemap:

```txt title="public/robots.txt"
User-agent: *
Allow: /

Sitemap: https://example.com/sitemap-index.xml
```

## RSS Feed

See [RSS Feed](/docs/guides/rss). Add the `<link>` in your Fumadocs config's [`head` component](/docs/astro/layouts#head).

`page.data` has no `lastModified`, add a date to the [frontmatter schema](/docs/astro/content#frontmatter), like `date: z.coerce.date()`, and use `page.data.date`.
