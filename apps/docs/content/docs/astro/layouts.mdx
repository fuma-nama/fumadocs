## Overview

The integration renders pages with [Fumadocs UI](/docs/ui) layouts. You customize them with React modules that run in the browser as islands:

| Module   | Exports                                          |
| -------- | ------------------------------------------------ |
| `layout` | `baseOptions()`, layout options, and `Provider`. |
| `page`   | The docs page component, as default export.      |

## Layout Options

Create a module exporting `baseOptions()`, which returns the [layout options](/docs/ui/layouts/docs), JSX included:

<include cwd meta='tab="src/lib/layout.shared.tsx"'>
  ../../examples/astro/src/lib/layout.shared.tsx
</include>

```js tab="astro.config.mjs"
fumadocs({
  layout: './src/lib/layout.shared.tsx', // [!code ++]
});
```

The options apply to every layout: docs pages, custom pages and the 404 page.

> Without it, the navbar shows your Fumadocs config's `title`.

## Provider

The integration renders the [root provider](/docs/ui/layouts/root-provider) for you. To render components inside it like WebMCP, export `Provider` from the `layout` module:

```tsx title="src/lib/layout.shared.tsx"
import type { ReactNode } from 'react';
import { WebMCP } from '@/components/webmcp';

export function Provider({ children }: { children: ReactNode }) {
  return (
    <>
      <WebMCP />
      {children}
    </>
  );
}
```

It wraps every layout, but not the content components -- those render in their own islands.

## Docs Page

The docs page is a React component, like `page.tsx` on other frameworks. Create a module whose default export renders it:

<include cwd meta='tab="src/components/docs.tsx"'>
  ../../examples/astro/src/components/docs.tsx
</include>

```js tab="astro.config.mjs"
fumadocs({
  page: './src/components/docs.tsx', // [!code ++]
});
```

It receives:

- `tree`: the page tree.
- `layout`: the `baseOptions()` result.
- `page`: page data.
- `children`: the content.

<auto-type-table path="./props.ts" name="DocsPageData" />

Use any Fumadocs UI layout or component here, such as the [Notebook layout](/docs/ui/layouts/notebook) for some pages:

```tsx title="src/components/docs.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import { DocsLayout as NotebookLayout } from 'fumadocs-ui/layouts/notebook'; // [!code ++]
import type { DocsPageProps } from '@fumadocs/astro/config';

export default function Docs({ tree, page, layout, children }: DocsPageProps) {
  // `type` is the key of its source in `loader()`
  const Layout = page.type === 'api' ? NotebookLayout : DocsLayout;
  // ...
}
```

## Custom Pages

Use `HomeLayout.astro` for custom pages, with the navbar from your layout options:

<include cwd meta='title="src/pages/index.astro"'>
  ../../examples/astro-min/src/pages/index.astro
</include>

Anything in its `head` slot goes into `<head>`. Props: `title`, `description`, `lang` (for [internationalization](/docs/astro/internationalization)) and `notFound`.

Your pages can read your docs from the source:

```astro title="src/pages/all.astro"
---
import HomeLayout from '@fumadocs/astro/components/HomeLayout.astro';
import { source } from '@/lib/source';
---

<HomeLayout title="All Pages">
  <ul>
    {source.getPages().map((page) => <li><a href={page.url}>{page.data.title}</a></li>)}
  </ul>
</HomeLayout>
```

A custom page takes priority over a docs page at the same URL. Remove the MDX file to avoid a warning from Astro. To replace the 404 page, create `src/pages/404.astro`.

### React Content

Render React content with `ReactContent.astro` to hydrate it like docs content: it renders on the server and your [MDX components](/docs/astro/content#mdx-components) hydrate, like code block copy buttons.

```astro title="src/pages/changelog.astro"
---
import { createElement } from 'react';
import HomeLayout from '@fumadocs/astro/components/HomeLayout.astro';
import ReactContent from '@fumadocs/astro/components/ReactContent.astro';
import { Timeline } from '@/components/timeline';
---

<HomeLayout title="Changelog">
  <ReactContent node={createElement(Timeline)} />
</HomeLayout>
```

## Head

Add tags to the `<head>` of every page with an Astro component:

<include cwd meta='tab="src/components/Head.astro"'>
  ../../examples/astro/src/components/Head.astro
</include>

```ts tab="src/fumadocs.config.ts"
import Head from './components/Head.astro';

export default defineConfig({
  // ...
  head: Head, // [!code ++]
});
```

On docs pages, it receives page data as `page`.

## Styles

The pages load `src/styles/global.css`, see [Themes](/docs/ui/theme) for its colors and presets. Set `css` for another file:

```js title="astro.config.mjs"
fumadocs({
  css: './src/styles/docs.css', // [!code ++]
});
```
