## Setup

`graphqlPlugin()` renders [GraphQL](/docs/integrations/graphql) pages.

```npm
npm i @fumadocs/graphql graphql shiki
```

Add its styles:

```css title="src/styles/global.css"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
/* [!code ++] */
@import '@fumadocs/graphql/css/preset.css';
```

Create the [GraphQL server](/docs/integrations/graphql/server) from your schema:

```ts title="src/lib/graphql.ts"
import { createGraphQL } from '@fumadocs/graphql/server';

export const graphql = createGraphQL({
  input: ['./schema.graphql'],
});
```

Add its pages to your source:

```ts title="src/lib/source.ts"
import { getCollection } from 'astro:content';
import { loader } from 'fumadocs-core/source';
import { toFumadocsSource } from '@fumadocs/astro/source';
import { graphql } from './graphql'; // [!code ++]

export const source = loader({
  source: {
    docs: toFumadocsSource(await getCollection('docs'), await getCollection('meta')),
    // `baseUrl` of the loader, to link types and operations [!code ++:2]
    graphql: await graphql.staticSource({ baseDir: 'graphql', baseUrl: '/docs' }),
  },
  baseUrl: '/docs',
  // adds the kind of items to each page in the sidebar [!code ++:2]
  plugins: [graphql.loaderPlugin()],
});
```

It generates a page per operation and named type under `/docs/graphql`, grouped into folders by their kind. Generated MDX files are not supported, use `staticSource()` above.

Render them with the plugin:

```ts title="src/fumadocs.config.ts"
import { defineConfig } from '@fumadocs/astro/config';
import { graphqlPlugin } from '@fumadocs/astro/plugins/graphql'; // [!code ++]
import { source } from './lib/source';
import { graphql } from './lib/graphql'; // [!code ++]

export default defineConfig({
  source,
  plugins: [graphqlPlugin({ server: graphql })], // [!code ++]
});
```

The plugin serves the schemas left out by `includeSchema: false`, so pages load them once per browser session.

To customize the pages, create `<GraphQLPage />` with [`createGraphQLPage()`](/docs/integrations/graphql/api-page) and add it to your MDX components, loaded lazily (see [Lazy Components](/docs/astro/content#lazy-components)).
