## Introduction

`@fumadocs/astro` is the Astro integration of Fumadocs. You write MDX files, it creates the docs site:

- Docs pages, search, `llms.txt` and the 404 page, with no route files to write.
- The UI of [Fumadocs UI](/docs/ui), rendered as React islands.
- A static site, every route is prerendered.

## Create a Site

Astro 7 requires Node.js 22.23.4 or later.

```npm
npx create-fumadocs-app@latest my-docs --template astro
```

Start the dev server, and open `/docs`:

```npm
npm run dev
```

| File                        | For                                                            |
| --------------------------- | -------------------------------------------------------------- |
| `content/docs`              | Your docs pages.                                               |
| `src/fumadocs.config.ts`    | The site: its pages, title and plugins.                        |
| `src/lib/source.ts`         | The source of pages, created with `loader()`.                  |
| `src/content.config.ts`     | The content collections of your docs.                          |
| `src/lib/layout.shared.tsx` | The [`layout` module](/docs/astro/layout): navbar and links.   |
| `src/components/mdx.tsx`    | The [`components` module](/docs/astro/writing#mdx-components). |
| `src/pages/index.astro`     | The home page, an Astro page of your own.                      |
| `src/styles/global.css`     | Tailwind CSS and the styles of Fumadocs UI.                    |
| `astro.config.mjs`          | Adds the Fumadocs integration, and registers your modules.     |

The template also generates [OG images](/docs/astro/og-image).

### Write a Page

Edit the first page, or add one next to it:

```mdx title="content/docs/hello.mdx"
---
title: Hello
description: My second page
---

## Overview

I love Fumadocs.
```

It is available at `/docs/hello`.

## Coming From

- **An existing Astro project:** see [Manual Installation](/docs/astro/manual-installation).
- **Fumadocs on another framework:** there are no docs routes, layouts or providers to write. Layout options go to the [`layout` module](/docs/astro/layout), the docs page to the [`page` module](/docs/astro/page).
- **The setup with your own routes:** it keeps working when there is no `src/fumadocs.config.ts`, see [Without the Config File](/docs/astro/without-config).
