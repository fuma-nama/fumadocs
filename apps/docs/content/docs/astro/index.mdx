## Overview

`@fumadocs/astro` brings Fumadocs to [Astro](https://astro.build). You write MDX files, the integration builds the docs site around them:

- Docs pages, search, `llms.txt` and the 404 page are created for you, with no routes, layouts or providers in your app.
- [Fumadocs UI](/docs/ui) renders as React islands.
- Features like OG images and OpenAPI pages are [plugins](/docs/astro/plugins).

## Quick Start

Create a new app, it requires Node.js 22.23.4 or later:

```npm
npx create-fumadocs-app@latest my-docs --template astro
```

Start the dev server, and open `/docs`:

```npm
npm run dev
```

To add Fumadocs to an existing Astro app, see [Manual Installation](/docs/astro/manual-installation).
