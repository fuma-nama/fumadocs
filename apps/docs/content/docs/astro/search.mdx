## Overview

Search works out of the box: the integration exports the search indexes of your pages at build time, and the search dialog searches them in the browser, with the [built-in search](/docs/headless/search/orama).

Search is made of:

- **Engine:** where results come from, used through its search hook.
- **Dialog:** how results are shown.

Replace either one from the [`layout` module](/docs/astro/layouts#layout-options).

## Search Engine

Export `useSearch()` to use another engine in the built-in dialog, with the search hook of the engine:

```tsx title="src/lib/layout.shared.tsx"
import { liteClient } from 'algoliasearch/lite';
import { useAlgoliaSearch } from 'fumadocs-core/search/client';

const client = liteClient('app id', 'search api key');

export function useSearch({ locale }: { locale?: string }) {
  return useAlgoliaSearch({ client, indexName: 'docs', locale });
}
```

To sync your pages to the engine, see the guide of your engine, like [Algolia](/docs/search/algolia).

## Search Dialog

Export `SearchDialog` to replace the dialog, it is a [search dialog](/docs/ui/search#custom-ui) of Fumadocs UI:

```tsx title="src/lib/layout.shared.tsx"
export { default as SearchDialog } from '@/components/search';
```

Fumadocs CLI creates it for your engine:

```npm
npx @fumadocs/cli feature search --provider algolia
```

## Search Index

The built-in index is left out when the `layout` module exports `useSearch` or `SearchDialog`. Add its plugin to keep it, or to pass the [options of `createFromSource()`](/docs/headless/search/orama):

```ts title="src/fumadocs.config.ts"
import { oramaSearchPlugin } from '@fumadocs/astro/plugins/orama-search';

export default defineConfig({
  // ...
  plugins: [oramaSearchPlugin({ language: 'english' })], // [!code ++]
});
```

Your own dialog can search it with `useStaticSearch()` of `fumadocs-core/search/client`.
