## Overview

Features of your site come from plugins, like the routes of search and LLMs. Add them to your config:

```ts title="src/fumadocs.config.ts"
import { defineConfig } from '@fumadocs/astro/config';
import { takumiPlugin } from '@fumadocs/astro/plugins/takumi'; // [!code ++]
import { source } from './lib/source';

export default defineConfig({
  source,
  plugins: [takumiPlugin()], // [!code ++]
});
```

| ------------------------ | ----------------------------------------- | -------------------------------------------- |
| `oramaSearchPlugin()`    | `@fumadocs/astro/plugins/orama-search`    | [Search](/docs/astro/search)                 |
| `flexsearchPlugin()`     | `@fumadocs/astro/plugins/flexsearch`      | [FlexSearch](/docs/astro/search#flexsearch)  |

| `takumiPlugin()`         | `@fumadocs/astro/plugins/takumi`          | [OG Images](/docs/astro/og-image)            |
| `gitPlugin()`            | `@fumadocs/astro/plugins/git`             | [Git](/docs/astro/git)                       |
| `linkValidationPlugin()` | `@fumadocs/astro/plugins/link-validation` | [Validate Links](/docs/astro/validate-links) |
| `mcpPlugin()`            | `@fumadocs/astro/plugins/mcp`             | [MCP](/docs/astro/llms#mcp-server)           |

### Default Plugins

`oramaSearchPlugin()` and `llmsPlugin()` are added by default. Add one yourself to pass its options, it replaces the default one:

```ts title="src/fumadocs.config.ts"
import { oramaSearchPlugin } from '@fumadocs/astro/plugins/orama-search';

export default defineConfig({
  // ...
  plugins: [oramaSearchPlugin({ language: 'english' })], // [!code ++]
});
```

To remove them, set `preset` to `false`.

## Writing Plugins

A plugin is an object, its hooks receive the app as `this`, like `this.getPages()` for the pages of every language:

<auto-type-table path="./props.ts" name="Plugin" />

For example, a plugin that serves the URLs of pages, and opens API pages in full width:

```ts title="src/lib/my-plugin.ts"
import type { Plugin } from '@fumadocs/astro/config';

export function myPlugin(): Plugin {
  return {
    name: 'my-plugin',
    routes() {
      const urls = this.getPages().map((page) => page.url);

      return [
        {
          type: 'file',
          url: `${this.base}/pages.json`,
          GET: () => Response.json(urls),
        },
      ];
    },
    transformPage(page, data) {
      return page.slugs[0] === 'api' ? { ...data, full: true } : data;
    },
  };
}
```

`transformPage()` changes the [data of docs pages](/docs/astro/layouts#docs-page), received by the `page` module and used for the `<head>` tags like the title.

A route of `type: 'page'` renders an Astro component with `props`, use [`HomeLayout.astro`](/docs/astro/layouts#your-own-pages) in it for the layout.

An item of `plugins` can also be an array of plugins, `false` and `undefined` are skipped:

```ts
plugins: [myPlugin(), import.meta.env.PROD && takumiPlugin()];
```

### Content Sources

The pages of your own [content source](/docs/headless/source-api/source) are rendered by a plugin, the official ones have [plugins](/docs/astro/content#other-content-sources). `getBody()` returns their content as React nodes, rendered with your MDX components (`this.components`) so they hydrate like MDX content.

For example, pages with MDX from a CMS, compiled by [MDX Remote](/docs/integrations/content/mdx-remote):

```ts title="src/lib/cms-plugin.ts"
import type { Plugin } from '@fumadocs/astro/config';
import { createCompiler } from '@fumadocs/mdx-remote';
import { createElement } from 'react';

const compiler = createCompiler();

/** renders pages with MDX in `page.data.mdx` */
export function cmsPlugin(): Plugin {
  return {
    name: 'cms',
    async getBody(page) {
      const { mdx } = page.data as { mdx?: string };
      if (typeof mdx !== 'string') return;
      const { body, toc } = await compiler.compile({ source: mdx });
      return { node: createElement(body, { components: this.components }), toc };
    },
    getText(page) {
      const { mdx } = page.data as { mdx?: string };
      if (typeof mdx === 'string') return mdx;
    },
  };
}
```

Search indexes the `structuredData` of page data, and a `lastModified` date shows as the last updated time of pages.

### Server Routes

Routes are generated at build time. Set `prerender: false` to handle requests on the server, it requires an [adapter of Astro](https://docs.astro.build/en/guides/on-demand-rendering/):

```ts
routes() {
  return [
    {
      type: 'file',
      url: `${this.base}/api/feedback`,
      prerender: false,
      POST: async ({ request }) => Response.json(await request.json()),
    },
  ];
},
```

A `middleware` hook runs as an [Astro middleware](https://docs.astro.build/en/guides/middleware/), for prerendered pages at build time too, see `context.isPrerendered`.
