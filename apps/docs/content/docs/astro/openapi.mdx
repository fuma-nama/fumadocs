## Setup

`openapiPlugin()` renders the pages of [Fumadocs OpenAPI](/docs/integrations/openapi), with the interactive playground.

```npm
npm i fumadocs-openapi shiki
```

Add its styles:

```css title="src/styles/global.css"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
/* [!code ++] */
@import 'fumadocs-openapi/css/preset.css';
```

Create the OpenAPI server from your schema:

<include cwd meta='title="src/lib/openapi.ts"'>
  ../../examples/astro/src/lib/openapi.ts
</include>

### Pages

Add its pages to your source with `multiple()`:

```ts title="src/lib/source.ts"
import { getCollection } from 'astro:content';
import { loader, multiple } from 'fumadocs-core/source'; // [!code ++]
import { toFumadocsSource } from '@fumadocs/astro/source';
import { openapi } from './openapi'; // [!code ++]

export const source = loader({
  source: multiple({
    docs: toFumadocsSource(await getCollection('docs'), await getCollection('meta')),
    api: await openapi.staticSource({ baseDir: 'api' }), // [!code ++]
  }),
  baseUrl: '/docs',
  // adds a badge to each page in the sidebar [!code ++]
  plugins: [openapi.loaderPlugin()],
});
```

It generates a page per operation under `/docs/api`, see [Generating Pages](/docs/integrations/openapi/generate-files) to customize them.

Render them with the plugin:

```ts title="src/fumadocs.config.ts"
import { defineConfig } from '@fumadocs/astro/config';
import { openapiPlugin } from '@fumadocs/astro/plugins/openapi'; // [!code ++]
import { source } from './lib/source';

export default defineConfig({
  source,
  plugins: [openapiPlugin()], // [!code ++]
});
```

The pages use the full width, and their Markdown for LLMs is the description of the operation.

> The plugin renders with the default options of `createOpenAPIPage()`, the [proxy](/docs/integrations/openapi/server#creating-proxy) and the [OAuth redirect](/docs/integrations/openapi/server#oauth-redirect) aren't supported yet.
