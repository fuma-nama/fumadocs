## Setup

`openapiPlugin()` renders [OpenAPI](/docs/integrations/openapi) pages with the interactive playground.

```npm
npm i fumadocs-openapi shiki
```

Add its styles:

```css title="src/styles/global.css"
@import 'tailwindcss';
@import 'fumadocs-ui/css/neutral.css';
@import 'fumadocs-ui/css/preset.css';
/* [!code ++] */
@import 'fumadocs-openapi/css/preset.css';
```

Create the [OpenAPI server](/docs/integrations/openapi/server) from your schema:

<include cwd meta='title="src/lib/openapi.ts"'>
  ../../examples/astro/src/lib/openapi.ts
</include>

Add its pages to your source:

```ts title="src/lib/source.ts"
import { getCollection } from 'astro:content';
import { loader } from 'fumadocs-core/source';
import { toFumadocsSource } from '@fumadocs/astro/source';
import { openapi } from './openapi'; // [!code ++]

export const source = loader({
  source: {
    docs: toFumadocsSource(await getCollection('docs'), await getCollection('meta')),
    api: await openapi.staticSource({ baseDir: 'api' }), // [!code ++]
  },
  baseUrl: '/docs',
  // adds a badge to each page in the sidebar [!code ++]
  plugins: [openapi.loaderPlugin()],
});
```

It generates a page per operation under `/docs/api`, see [Generating Pages](/docs/integrations/openapi/generate-files) to customize them. Generated MDX files are not supported, use `staticSource()` above.

Render them with the plugin:

```ts title="src/fumadocs.config.ts"
import { defineConfig } from '@fumadocs/astro/config';
import { openapiPlugin } from '@fumadocs/astro/plugins/openapi'; // [!code ++]
import { source } from './lib/source';
import { openapi } from './lib/openapi'; // [!code ++]

export default defineConfig({
  source,
  plugins: [openapiPlugin({ server: openapi })], // [!code ++]
});
```

The plugin follows your server: it serves the documents left out by `includeDocument: false`, and the proxy at `proxyUrl` when it is a pathname (requires an [Astro adapter](https://docs.astro.build/en/guides/on-demand-rendering/)). See [OpenAPI server options](/docs/integrations/openapi/server).

Pass proxy options with `createProxy`, or `false` when the proxy is served elsewhere:

```ts title="src/fumadocs.config.ts"
openapiPlugin({
  server: openapi,
  createProxy: { allowedOrigins: ['https://api.example.com'] }, // [!code ++]
});
```

To customize the pages, create `<OpenAPIPage />` with [`createOpenAPIPage()`](/docs/integrations/openapi/api-page) and add it to your MDX components, loaded lazily (see [Lazy Components](/docs/astro/content#lazy-components)).
