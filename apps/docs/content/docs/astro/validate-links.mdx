---
title: Validate Links
description: Fail the build on broken links.
---

## Setup

`linkValidationPlugin()` checks links in your pages with [next-validate-link](https://next-validate-link.vercel.app) when you build, and fails the build on a broken one.

```npm
npm i next-validate-link
```

```ts title="src/fumadocs.config.ts"
import { defineConfig } from '@fumadocs/astro/config';
import { linkValidationPlugin } from '@fumadocs/astro/plugins/link-validation'; // [!code ++]
import { source } from './lib/source';

export default defineConfig({
  source,
  plugins: [linkValidationPlugin()], // [!code ++]
});
```

Links can point to your pages and their headings, plugin routes, Astro pages and `public/` files:

```text
[Fumadocs] broken links:
In "content/docs/index.mdx:12:1": link "/docs/missing" not-found
```

## Options

It takes the [`validateFiles()` options](https://next-validate-link.vercel.app), like `whitelist` for links to skip and `checkExternal` for absolute URLs:

```ts title="src/fumadocs.config.ts"
linkValidationPlugin({
  whitelist: (href) => href.startsWith('/api/'),
  checkExternal: true,
});
```

`href` attributes of `Card` are checked by default, change the components with `markdown.components`.
