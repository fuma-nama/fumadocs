## The `page` Module

Docs pages render the [Docs Layout](/docs/ui/layouts/docs) by default. To change them, write the `page` module, a file whose default export is the docs page:

```js title="astro.config.mjs"
fumadocs({
  page: './src/components/docs.tsx', // [!code ++]
});
```

This is the default page, start from it:

```tsx title="src/components/docs.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/docs';
import {
  DocsDescription,
  DocsPage,
  DocsTitle,
  MarkdownCopyButton,
  ViewOptionsPopover,
} from 'fumadocs-ui/layouts/docs/page';
import type { DocsPageProps } from '@fumadocs/astro/config';

/**
 * The docs page, the content is passed as children.
 */
export default function Docs({ tree, page, layout, children }: DocsPageProps) {
  return (
    <DocsLayout {...layout} tree={tree}>
      <DocsPage toc={page.toc} full={page.full}>
        <DocsTitle>{page.title}</DocsTitle>
        <DocsDescription>{page.description}</DocsDescription>
        {page.markdownUrl && (
          <div className="flex flex-row gap-2 items-center border-b -mt-4 pb-6">
            <MarkdownCopyButton markdownUrl={page.markdownUrl} />
            <ViewOptionsPopover markdownUrl={page.markdownUrl} />
          </div>
        )}
        {children}
      </DocsPage>
    </DocsLayout>
  );
}
```

It is a React component rendered as an island, the content of the page is `children`.

### Props

| Prop       | Description                                                   |
| ---------- | ------------------------------------------------------------- |
| `tree`     | The page tree of the current language.                        |
| `page`     | The data of the page, see below.                              |
| `layout`   | `baseOptions()` of the [`layout` module](/docs/astro/layout). |
| `children` | The content of the page.                                      |

`page` has:

| Property      | Description                                                  |
| ------------- | ------------------------------------------------------------ |
| `title`       | Title from frontmatter.                                      |
| `description` | Description from frontmatter.                                |
| `url`         | URL of the page.                                             |
| `path`        | File path, relative to the content directory.                |
| `locale`      | Language of the page, with i18n.                             |
| `type`        | Key of its source in `multiple()`.                           |
| `toc`         | Table of contents.                                           |
| `full`        | Use the full width of page, set on OpenAPI pages.            |
| `markdownUrl` | URL of the page as Markdown, from [LLMs](/docs/astro/llms).  |
| `image`       | URL of the OG image, from [OG Images](/docs/astro/og-image). |

## Examples

### Edit on GitHub

Link to the source file of each page:

```tsx title="src/components/docs.tsx"
// [!code ++]
const githubUrl = `https://github.com/acme/docs/blob/main/content/docs/${page.path}`;

<ViewOptionsPopover markdownUrl={page.markdownUrl} githubUrl={githubUrl} />;
```

### Feedback

Fumadocs CLI adds the [Feedback](/docs/integrations/feedback) component to your `page` module, and creates the module when it is missing:

```npm
npx @fumadocs/cli feature feedback
```

### Other Layouts

Import another docs layout, like [Notebook](/docs/ui/layouts/notebook):

```tsx title="src/components/docs.tsx"
import { DocsLayout } from 'fumadocs-ui/layouts/notebook'; // [!code highlight]
import {
  DocsDescription,
  DocsPage,
  DocsTitle,
  MarkdownCopyButton,
  ViewOptionsPopover,
} from 'fumadocs-ui/layouts/notebook/page'; // [!code highlight]
```

To edit the layout itself, copy its source into your project with Fumadocs CLI, it writes the `page` module for the layout you pick:

```npm
npx @fumadocs/cli customize
```
