Fumadocs MDX provides MDX presets to simplify configurations of features like **syntax highlighting**.

It compiles with unified by default. A collection can compile with [Sätteri](#satteri) instead, which has a preset of the same plugins.

## Default Preset

A preset designed for documentation sites, it is enabled by default for global MDX options.

To override the defaults, it accepts an interface inherited from [`ProcessorOptions`](https://mdxjs.com/packages/mdx/#processoroptions):

### Remark Plugins

These plugins are applied by default:

- Remark GFM - [GitHub Flavored Markdown](https://github.github.com/gfm).
- [Remark Heading](/docs/headless/mdx/headings) - Extract table of contents.
- [Remark Image](/docs/headless/mdx/remark-image) - Handle images.
- [Remark Code Tab](/docs/markdown#tab-groups) - Code block tab groups.
- [Remark NPM](/docs/headless/mdx/remark-npm) - Package manager commands.
- [Remark Structure](/docs/headless/mdx/structure) - Generate search indexes.

[Include](/docs/mdx/include) is always enabled, also outside the preset.

Add other remark plugins with:

```ts tab="Global Config"
import { defineConfig } from 'fumadocs-mdx/config';
import { myPlugin } from './remark-plugin';

export default defineConfig({
  mdxOptions: {
    remarkPlugins: [myPlugin],
    // You can also pass a function to control the order of remark plugins.
    remarkPlugins: (v) => [myPlugin, ...v],
  },
});
```

```ts tab="Collection Config"
import { defineCollections, applyMdxPreset } from 'fumadocs-mdx/config';
import { myPlugin } from './remark-plugin';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: applyMdxPreset({
    remarkPlugins: [myPlugin],
    // You can also pass a function to control the order of remark plugins.
    remarkPlugins: (v) => [myPlugin, ...v],
  }),
});
```

### Rehype Plugins

These plugins are applied by default:

- [Rehype Code](/docs/headless/mdx/rehype-code) - Syntax highlighting.
- [Rehype TOC](/docs/headless/mdx/headings#rehype-toc) - Export table of contents.

Same as remark plugins, you can pass an array or a function to add other rehype plugins.

```ts tab="Global Config"
import { defineConfig } from 'fumadocs-mdx/config';
import { myPlugin } from './rehype-plugin';

export default defineConfig({
  mdxOptions: {
    rehypePlugins: (v) => [myPlugin, ...v],
  },
});
```

```ts tab="Collection Config"
import { defineCollections, applyMdxPreset } from 'fumadocs-mdx/config';
import { myPlugin } from './rehype-plugin';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: applyMdxPreset({
    rehypePlugins: (v) => [myPlugin, ...v],
  }),
});
```

### Customize Built-in Plugins

Customize the options of built-in plugins like:

```ts tab="Global Config"
import { defineConfig } from 'fumadocs-mdx/config';

export default defineConfig({
  mdxOptions: {
    rehypeCodeOptions: {
      // options
    },
    remarkImageOptions: {
      // set image placeholder to `blur` (only effective on Next.js)
      placeholder: 'blur',
    },
    remarkHeadingOptions: {
      // options
    },
  },
});
```

```ts tab="Collection Config"
import { defineCollections, applyMdxPreset } from 'fumadocs-mdx/config';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: applyMdxPreset({
    rehypeCodeOptions: {
      // options
    },
    remarkImageOptions: {
      // options
    },
    remarkHeadingOptions: {
      // options
    },
  }),
});
```

## Sätteri [#satteri]

[Sätteri](https://github.com/bruits/satteri) is a compiler with its own plugin model. Install it:

```package-install
@fumadocs/satteri satteri
```

Set `compiler: 'satteri'` on a [collection](/docs/mdx/collections#compiler). It reads the global `satteriOptions`:

```ts title="source.config.ts"
import { defineConfig, defineDocs } from 'fumadocs-mdx/config';
import { remarkSteps } from '@fumadocs/satteri/remark-steps';

export const docs = defineDocs({
  docs: {
    compiler: 'satteri',
  },
});

export default defineConfig({
  satteriOptions: {
    // in place of remark plugins, and `hastPlugins` in place of rehype plugins
    mdastPlugins: [remarkSteps()],
    // built-in plugins take the same options as in `mdxOptions`
    rehypeCodeOptions: {
      themes: { light: 'github-light', dark: 'github-dark' },
    },
  },
});
```

Remark and rehype plugins don't run on Sätteri. Fumadocs ports its plugins to `@fumadocs/satteri/<name>`, like `@fumadocs/satteri/remark-steps`. Both plugin options accept an array or a function, like `mdxOptions`.

The preset applies the same plugins as on unified. GFM and directives are parser `features` enabled by default, and `features: { math: true }` also renders [math](/docs/markdown/math) with KaTeX.

The global `compiler` option only selects the compiler of MDX files outside collections.

## Source Map

Source maps are disabled by default on unified, since generating them slows down compilation.

To enable, install `source-map` and pass its generator to MDX options:

```npm
npm i -D source-map
```

```ts tab="Global Config" title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';
import { SourceMapGenerator } from 'source-map';

export default defineConfig({
  mdxOptions: {
    SourceMapGenerator,
  },
});
```

```ts tab="Collection Config"
import { defineCollections, applyMdxPreset } from 'fumadocs-mdx/config';
import { SourceMapGenerator } from 'source-map';

export const blog = defineCollections({
  type: 'doc',
  mdxOptions: applyMdxPreset({
    SourceMapGenerator,
  }),
});
```

Errors thrown from compiled content can now be traced back to the original Markdown file.
