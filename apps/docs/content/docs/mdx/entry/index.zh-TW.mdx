## 概覽 [#overview]

在設定檔中定義集合後，集合項目會編譯成應用程式可存取的 JavaScript 檔案。

編譯工作雖然由 Fumadocs MDX 的打包工具／執行階段外掛負責，但它也會產生**進入點檔案**，讓您存取集合的輸出內容。

如果您偏好在應用程式模組中定義集合，請參閱 [Macro API](/docs/mdx/macro)。

### 進入點檔案 [#entry-files]

集合的輸出會產生在輸出目錄中，您可以透過進入點檔案存取。

<Files>
  <Folder name=".source" defaultOpen>
    <File name="server.ts" />

    <File name="browser.ts" />

    <File name="dynamic.ts" />
  </Folder>
</Files>
